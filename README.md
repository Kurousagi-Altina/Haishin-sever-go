# 直播平台 - Live Broadcast Platform

基于 Go 后端 + 纯前端的前后端分离直播平台，集成 ZLMediaKit 流媒体服务，支持双通道鉴权（门禁口令 + 用户账号）、用户注册与管理、直播间列表浏览、FLV 直播流播放、云盘文件上传/下载/管理，以及基于 `action_logs` 的全量操作行为记录与管理后台。

### 鉴权体系说明

系统支持**两套鉴权通道**，可同时使用：

| 通道 | 入口 | 方式 | Token 角色 | 适用场景 |
|------|------|------|-----------|----------|
| 门禁口令 | `POST /api/verify` | 输入共享口令 | `door` | 快速访问，无需注册 |
| 用户账号 | `POST /api/login` | 用户名+密码登录 | `user` / `admin` | 注册用户，可跳过门禁口令 |

- **门禁口令用户**: 进入后仅能观看直播，无用户身份，不可访问管理后台
- **普通注册用户**: 登录后直接进入直播大厅，跳过门禁口令页面
- **管理员**: 登录后可访问管理后台 `/admin.html`，管理用户和查看所有记录

### 用户注册与审核流程

```
用户点击"注册" → 填写用户名+密码 → 提交申请(状态: pending)
                                            ↓
                              管理员在后台看到待审核申请
                                            ↓
                              ┌──── 通过 ────┴──── 拒绝 ────┐
                              ↓                              ↓
                        状态变为 active                  用户被删除
                              ↓
                      用户可正常登录使用
```

## 数据流说明

1. **门禁口令流程**: 前端发送口令 → 后端校验 → 签发 `door` 角色 Token → 记录鉴权日志 + 操作日志
2. **用户登录流程**: 前端发送用户名+密码 → 后端 bcrypt 校验 → 签发含角色 Token → 跳过门禁页面直接进入 → 记录操作日志
3. **直播列表流程**: 前端携带 Token 请求 → 后端代理转发到 ZLM API → 过滤返回唯一流列表
4. **视频播放流程**: 前端获取流地址后，直接从 ZLM 服务器拉取 FLV 流播放（不经过 Go 后端）→ 记录观看日志 + 操作日志
5. **操作日志**: 所有关键行为（验证、注册、登录、观看、上传、下载等）均通过 `action_logs` 表记录，含 IP、用户名、操作类型、详情
6. **管理员审核**: 管理员登录后台 → 查看待审核用户 → 通过/拒绝注册申请
7. **云盘文件**: 前端携带 Token 请求 → 后端列出/上传/下载/管理 `/userdata/download/` 目录中的文件，支持子目录导航（`?path=` 参数）；游客仅可下载，注册用户可上传，管理员可新建文件夹/删除/移动文件；页面展示已用/总共空间及进度条（静默扣减 4GB 预留）；文件列表回显上传者名称，上传记录持久化到 `cloud_files` 表，管理员操作文件后上传者更新为管理员

## 数据库设计

使用 SQLite3（纯 Go 驱动 `modernc.org/sqlite`），数据库文件 `data.db` 在运行时自动创建。

### visitors - 页面访问记录

| 字段 | 类型 | 说明 |
|------|------|------|
| id | INTEGER | 主键自增 |
| ip | TEXT | 访问者 IP 地址 |
| user_agent | TEXT | 浏览器 User-Agent |
| path | TEXT | 访问路径 |
| visit_time | DATETIME | 访问时间（本地时间） |

### auth_attempts - 鉴权记录

记录所有门禁口令尝试和用户登录尝试。

| 字段 | 类型 | 说明 |
|------|------|------|
| id | INTEGER | 主键自增 |
| ip | TEXT | 尝试者 IP 地址 |
| password | TEXT | 尝试的口令或账号名 |
| success | INTEGER | 是否成功（0=失败, 1=成功） |
| attempt_time | DATETIME | 尝试时间（本地时间） |

### stream_views - 直播观看记录

| 字段 | 类型 | 说明 |
|------|------|------|
| id | INTEGER | 主键自增 |
| ip | TEXT | 观看者 IP 地址 |
| app | TEXT | 直播应用名 |
| stream | TEXT | 直播流名 |
| view_time | DATETIME | 观看时间（本地时间） |

### users - 用户账号

| 字段 | 类型 | 说明 |
|------|------|------|
| id | INTEGER | 主键自增 |
| username | TEXT | 用户名（唯一） |
| password_hash | TEXT | bcrypt 密码哈希 |
| role | TEXT | 角色：`admin` / `user` |
| status | TEXT | 状态：`active` / `pending` |
| created_at | DATETIME | 注册时间（本地时间） |

**种子数据**: 首次启动时自动创建管理员账号 `admin` / `krusgaltn`（密码使用 bcrypt 哈希存储）。

### cloud_files - 云盘文件上传者记录

| 字段 | 类型 | 说明 |
|------|------|------|
| filepath | TEXT | 文件相对路径（主键） |
| uploader | TEXT | 上传者用户名 |
| updated_at | DATETIME | 最后更新时间（本地时间） |

文件无记录时前端回显为 `admin`。管理员对文件执行移动/重命名操作时，上传者更新为管理员用户名。

### action_logs - 操作行为日志

统一记录所有关键操作，替代早期按请求全量记录的 visitors 表。

| 字段 | 类型 | 说明 |
|------|------|------|
| id | INTEGER | 主键自增 |
| ip | TEXT | 操作者 IP 地址 |
| username | TEXT | 关联用户名（未登录时为空） |
| action | TEXT | 操作类型：`verify` / `register` / `login` / `watch_stream` / `download` / `upload` 等 |
| detail | TEXT | 操作详情（如流名、文件名、成功/失败状态） |
| created_at | DATETIME | 操作时间（本地时间） |

- 用户登录、注册、观看直播、上传/下载文件等关键行为均写入此表
- 门禁口令验证也记录（username 为空，detail 包含成功/失败状态）
- 管理后台「操作记录」标签页从此表分页查询


## API 接口文档

### 公开接口（无需 Token）

#### POST /api/verify — 门禁口令验证

请求:
```json
{
  "password": "114514"
}
```

成功响应 (200):
```json
{
  "success": true,
  "token": "b8e98c9d86d9c1bd...",
  "role": "door"
}
```

失败响应 (401):
```json
{
  "success": false,
  "error": "口令错误"
}
```

#### POST /api/register — 用户注册

提交注册申请，状态为 pending，需管理员审核。

请求:
```json
{
  "username": "myuser",
  "password": "mypassword"
}
```

成功响应 (200):
```json
{
  "success": true,
  "message": "注册申请已提交，请等待管理员审核通过"
}
```

约束: 用户名 2-32 字符，密码至少 6 字符。

#### POST /api/login — 用户登录

仅 `status=active` 的用户可登录。

请求:
```json
{
  "username": "admin",
  "password": "krusgaltn"
}
```

成功响应 (200):
```json
{
  "success": true,
  "token": "0b5af9734f0f...",
  "username": "admin",
  "role": "admin"
}
```

失败响应 (401):
```json
{
  "success": false,
  "error": "用户名或密码错误"
}
```

> 未审核通过的用户登录会返回 "账号未审核通过或用户名密码错误"。

### 受保护接口（需要任意有效 Token）

Header: `Authorization: Bearer <token>`

#### GET /api/me — 获取当前用户信息

响应 (200):
```json
{
  "user_id": 1,
  "username": "admin",
  "role": "admin"
}
```

对于门禁口令 Token，`user_id=0, username="", role="door"`。

#### GET /api/streams — 获取直播列表

响应 (200):
```json
{
  "code": 0,
  "streams": [
    {
      "app": "live",
      "stream": "channel1",
      "totalReaderCount": 42
    }
  ]
}
```

#### GET /api/stream-url — 获取流播放地址

参数: `?app=live&stream=channel1`

响应 (200):
```json
{
  "url": "http://47.97.153.51/live/channel1.live.flv"
}
```

> 调用此接口自动记录 `stream_views`。

#### GET /api/stats — 获取访客统计（公开版）

响应 (200):
```json
{
  "total_visits": 128,
  "unique_visitors": 45,
  "auth_attempts": 60,
  "auth_success": 38,
  "stream_views": 120
}
```

#### GET /api/cloud/list?path=xxx — 获取云盘文件列表

返回指定目录内的所有文件和文件夹。

参数: `?path=subdir/nested`（可选，不传则列出根目录）

响应 (200):
```json
{
  "files": [
    {
      "name": "document.pdf",
      "size": 1048576,
      "isDir": false,
      "modTime": "2026-05-13 10:30:00",
      "uploader": "myuser"
    },
    {
      "name": "我的文件夹",
      "size": 4096,
      "isDir": true,
      "modTime": "2026-05-13 09:15:00",
      "uploader": "admin"
    }
  ],
  "path": ""
}
```

#### GET /api/cloud/download?file=xxx&path=xxx&token=xxx — 下载文件

此接口不走 AuthMiddleware，改为自行校验 Token，支持两种鉴权方式：

- Query 参数: `?token=xxx`（推荐，前端直接 `window.location` 跳转，浏览器流式下载不占内存）
- Authorization Header: `Bearer xxx`（备用）

参数: `?file=document.pdf&path=subdir&token=xxx`（`path` 可选，指定文件所在子目录）

返回文件二进制内容，响应头包含 `Content-Disposition: attachment`。

> 文件名经过路径穿越防护，仅允许下载 `/userdata/download/` 目录内的文件。

#### POST /api/cloud/upload?path=xxx — 上传文件

**权限**: 注册用户及以上（游客 `door` 角色返回 403）。

参数: `?path=subdir`（可选，上传到指定子目录）

请求: `multipart/form-data`，字段名 `file`。

限制: 单文件最大 100MB。

成功响应 (200):
```json
{
  "success": true,
  "filename": "document.pdf"
}
```

游客拒绝响应 (403):
```json
{
  "error": "游客无上传权限，请登录后操作"
}
```

#### GET /api/cloud/space — 获取磁盘空间

返回存储目录所在分区的磁盘空间信息，后端已静默扣减 4GB 系统预留。

响应 (200):
```json
{
  "total": 107374182400,
  "used": 5368709120,
  "free": 98000000000
}
```

> `total` 为分区总空间，`used` 为云盘目录实际占用大小（递归计算），`free` 为扣除 4GB 预留后的剩余可用字节。

#### POST /api/cloud/mkdir?path=xxx — 新建文件夹（admin）

请求:
```json
{
  "name": "新文件夹"
}
```

成功响应 (200):
```json
{ "success": true }
```

#### DELETE /api/cloud/delete?name=xxx&path=xxx — 删除文件/文件夹（admin）

参数: `?name=新文件夹&path=subdir`（`path` 可选，指定目标所在子目录；支持文件和文件夹删除，文件夹会递归删除）。

成功响应 (200):
```json
{ "success": true }
```

#### POST /api/cloud/move?path=xxx — 移动/重命名文件或文件夹（admin）

请求:
```json
{
  "from": "旧名称.txt",
  "to": "新名称.txt"
}
```

成功响应 (200):
```json
{ "success": true }
```

> 目标名称已存在时返回 409。

### 管理员接口（需要 admin 角色 Token）

全部以 `/api/admin/` 为前缀，非 admin 角色返回 403。

#### GET /api/admin/stats — 管理概览统计

响应格式同 `/api/stats`。

#### GET /api/admin/visitors?page=1 — 操作记录（分页）

从 `action_logs` 表分页查询，每页 50 条。返回字段：`ip`, `username`, `action`, `detail`, `created_at`。

#### GET /api/admin/auth-attempts?page=1 — 鉴权记录（分页）

每页 50 条。

#### GET /api/admin/stream-views?page=1 — 观看记录（分页）

每页 50 条。

#### GET /api/admin/users — 所有用户列表

#### GET /api/admin/pending-users — 待审核注册列表

#### POST /api/admin/approve-user — 通过注册申请

```json
{ "user_id": 2 }
```

#### POST /api/admin/reject-user — 拒绝（删除）注册申请

```json
{ "user_id": 2 }
```

#### DELETE /api/admin/users/{id} — 删除用户

不可删除 admin 角色用户。

#### POST /api/admin/change-password — 管理员修改自身密码

```json
{ "new_password": "newpass123" }
```

## 页面说明

### 主页面 (`/` — index.html)

- **顶部导航栏**: 未登录时显示"注册"和"登录"按钮；已登录时显示用户名 + 退出（管理员额外显示"管理后台"链接）
- **门禁口令弹窗**: 未登录且无缓存 Token 时显示；已登录用户自动跳过
- **注册弹窗**: 用户名 + 密码 + 确认密码，提交后等待管理员审核
- **登录弹窗**: 用户名 + 密码，成功后直接进入直播大厅
- **直播大厅**: 左侧频道列表（每 5 秒刷新），右侧 FLV 播放器
- **Token 缓存**: 用户/管理员登录 Token 存储于 localStorage（关闭浏览器不清除，3天内有效）；门禁口令不持久化，刷新页面需重新验证

### 管理后台 (`/admin.html`)

需以 admin 角色登录后访问，包含以下功能标签页：

| 标签 | 功能 |
|------|------|
| 概览 | 总操作数、独立IP、鉴权尝试/成功、直播观看次数统计卡片 |
| 操作记录 | 分页表格：IP、用户、操作类型、详情、时间 |
| 鉴权记录 | 分页表格：IP、尝试内容、成功/失败标记、时间 |
| 观看记录 | 分页表格：IP、App、Stream、时间 |
| 用户管理 | 待审核用户（通过/拒绝按钮）+ 所有用户列表（删除按钮） |

管理员可在管理后台修改自身密码。

### 云盘 (`/cloud.html`)

需鉴权后访问，支持门禁口令和用户登录两种方式。已登录用户自动跳过鉴权。权限分级：

- **游客**（门禁口令）: 仅可浏览文件列表和下载文件，无上传权限
- **注册用户**: 可浏览、下载、上传文件
- **管理员**: 除上传/下载外，还可新建文件夹、重命名文件/文件夹、删除文件/文件夹

功能包括：

- **存储空间**: 页面顶部展示「已用 X / 总共 Y」+ 进度条 + 右侧「剩余 Z」，后端静默扣减 4GB 系统预留
- **面包屑导航**: 文件列表上方显示路径层级，点击可快速跳转到任意父级目录
- **文件夹双击进入**: 文件夹行支持双击进入子目录，带有光标悬停效果和「进入」按钮
- **文件列表**: 表格展示文件名（文件夹/文件图标区分）、上传者、大小（文件夹显示 `-`）、修改时间，支持刷新。无记录的文件回显为 `admin`
- **文件下载**: 直接将带 Token 的下载 URL 交给浏览器处理，流式写入磁盘，不受文件大小限制
- **文件上传**: 注册用户及以上可用，选择本地文件后上传至当前目录，单文件最大 100MB
- **管理员操作**: 新建文件夹（输入名称即可）、重命名（弹窗输入新名称，调用 move API）、删除（确认弹窗后删除，支持文件和文件夹）
- **鉴权门禁**: 未登录用户可通过门禁口令或用户登录两个标签页进行身份验证

## 跑团桌面 (`/tabletop.html`)

类似 Owlbear Rodeo 的轻量虚拟桌面，Owlbear 挂掉时可作为备用。

- **房间 / 场景**: 注册用户可创建房间（房主即 GM，管理员也拥有 GM 权限），一个房间可准备多个场景，玩家只能看到 GM 激活的场景；场景里的墙、门窗、迷雾、房间笔记、触发区域、绘制、怪物和道具棋子都**绑定在当前地图上**——给场景换一张地图（或移除地图）时它们跟着旧地图收起来（存在服务器上，玩家看不到），换回那张图时原样回来；玩家角色的棋子（有主控或关联玩家角色卡）留在桌上。换场景 / 换地图时没生成的墙体规划（自动识别预览、描过的段）会清掉；复制「邀请链接」发给队友，访客可用门禁口令 + 昵称加入
- **地图**: 导入普通图片，或 Dungeondraft / DungeonFog 导出的 Universal VTT（`.dd2vtt` / `.uvtt` / `.df2vtt`，自动读取网格大小）；可按「横向格数」校准网格，调整偏移/颜色/每格距离/测距规则
- **棋子**: 上传图片到房间资产库，拖到地图上放置（也可直接把图片文件拖进地图），自动吸附网格；可设置名称、尺寸、HP 条、AC、圆形裁剪、旋转、对玩家隐藏、锁定、指定控制者。选中后直接用鼠标变换：拖四角以中心等比自由缩放（按住 Shift 吸附半格），拖顶部圆钮旋转（吸附 15°，按住 Alt 不吸附）；鼠标放在棋子上 Alt+滚轮旋转、Shift+滚轮缩放 10%。缩放只改图片大小，不改判定圆：判定圆按体型（中型半径 1 尺，大型 2、巨型 3、超巨型 4 尺，等比放大），没定体型的棋子第一次缩放时会先记下当时的体型
- **自由放置 / 细分吸附**: 右下角选择棋子松手时的吸附方式：自由放置（默认，停在任意位置）、吸附 1/4 格、半格、整格（只影响自己），选细分吸附时地图上会画出细分虚线；拖动时按住 Alt 临时不吸附，Shift+方向键按细分步长微调。棋子松手停在哪就是哪，不会被自动挪开（玩家仍不能拖着棋子穿墙）
- **常用操作**: Ctrl+Z 撤销 / Ctrl+Y（或 Ctrl+Shift+Z）重做自己的操作（移动、缩放旋转、改属性、新建、删除；只退回自己改过的字段，不会把别人同时改的血量等也退回去）；拖到一半按 Esc 或加第二根手指会把棋子放回原处；Delete 删除超过 3 个物件或先攻里的单位时会先确认；N 键 = 下一位（GM）/ 结束自己的回合；Ctrl+C / Ctrl+V 复制粘贴到鼠标位置（可跨场景）；Ctrl+D 原地复制。棋子可水平翻转。HP 输入框支持 `20`（设为 20）、`+5`（治疗）、`-3`（伤害，先扣临时生命）、`15+5`
- **生命值与倒地**: 只有玩家角色（玩家控制的棋子或关联人物卡的棋子）有死亡豁免，其他生物掉到 0 就死亡。生物从有血掉到 0 时自动处理：玩家角色加「😵 昏迷」并结束专注（溢出伤害不低于生命上限则当场死亡），GM 的怪物加「💀 死亡」，先攻里自动跳过已死亡的单位；治疗回到 0 以上时去掉昏迷 / 稳定并清空死亡豁免。轮到自己且 0 生命值时，先攻条上直接有「💀 死亡豁免」按钮。0 生命值的角色在属性面板显示死亡豁免（成功 / 失败各 3 格），点「🎲 掷」由服务器掷：≥10 成功、<10 失败、天然 1 记两次失败、天然 20 恢复 1 点生命值；三次成功 = 稳定，三次失败 = 死亡。0 生命值时再受伤记一次失败（重击两次），单次伤害不低于生命上限直接死亡；被治疗后计数清零。「长休」恢复满血、清除临时生命和死亡豁免、恢复棋子资源与关联角色卡的法术位 / 资源、力竭 −1。多选棋子时可以全体伤害 / 全体治疗 / 长休 / 加入先攻
- **玩家看到的怪物血量**: GM 控制的棋子，玩家只收到按比例分档的血量（默认 25% 一档、向上取整，设置里可改为精确 / 10% / 50% / 只显示是否存活），AC 和精确数值留在服务器；Boss 血条勾选「公开数值」时例外。玩家角色（玩家控制的棋子或关联人物卡的棋子）之间互相可见：血条上写「生命+临时 / 上限」（临时生命为 0 时只写生命，如 22+5/30、24/24），右上角显示 AC（棋子没填 AC 时用人物卡的）；先攻栏、状态栏、Boss 血条和点开别人棋子时的属性面板也用同样的写法
- **判定圈**: 每个生物有一个判定圆，代表身体实际占的地面范围（俯视的身体宽度），和图片大小无关；默认按体型取小圆（半径：中型 1 尺≈成人肩宽，小型 0.75、微型 0.5；更大的按占格边长等比放大：大型 2、巨型 3、超巨型 4 尺）。距离、触及 / 射程、掩护、范围法术是否波及都按判定圆计算（距离 = 圆心距离按测距规则 − 两个半径）。选中棋子、拖动和施放行动时会显示判定圆。在棋子属性「判定圈」里可改半径：GM 可以改所有棋子，玩家只能改分配给自己的
- **吸附跟随**: 在棋子属性「跟随」里选一个棋子，之后它移动时跟随者会一起平移（坐骑、魔宠、贴在身上的特效等），可以连续跟随；跟随者自己被拖动时只改变相对位置。由服务器同步，隐藏或锁定的跟随者也会跟着走
- **生物体型**: 棋子的「体型」（微型 / 小中型 / 大型 / 巨型 / 超巨型）决定吸附整格时对齐几格、默认判定圈的大小，图片大小可以不同；关联角色卡 / 怪物卡时按卡上的体型自动设置
- **测距规则**: 默认按实际长度（直线距离）计算，格子只作参考；设置里也可改为按格子计数（斜向 5-10-5 或斜向 = 1 格，此时尺子会高亮经过的格子）
- **移动距离**: 拖动棋子时按实际拖过的路线累计长度（绕路也算），显示「移动 X / 速度 Y」；战斗中轮到某个棋子时，它的移动（拖动、方向键）会累计到「本回合已移动」，先攻条上显示 🏃 已移动 / 速度，超过速度提示「需要疾走」，超过两倍提示「超出」，换回合自动清零。移动距离只是提示，超出速度不会阻止移动（只有墙、窗、关着的门会挡住玩家；按实际拖过的路线判断，可以绕过拐角）。速度取棋子属性面板里填的「速度」，没填时读关联角色卡
- **先攻 / 回合（⚔ 战斗）**: 选中棋子「加入先攻」，服务器掷先攻（d20 + 先攻加值，可优势 / 劣势），按先攻、加值、随机决胜排序；GM 开始战斗、切换上一位 / 下一位、结束战斗，轮次自动累计；轮到玩家时提醒，玩家可「结束我的回合」。地图上当前行动的棋子有金色圈，底部显示「第 N 轮 · 当前 · 下一位」
- **行动（选目标自动结算）**: 角色卡的武器、法术，怪物卡的动作（如吐息），特性旁边都有 ⚡ 按钮；战斗栏的「⚡ 自定义行动」可以从空白手动填写。行动框会自动识别攻击加值、伤害骰与类型、治疗 / 临时生命、豁免属性与 DC、成功减半、射程 / 触及、范围（球形、锥形、直线、立方，可从自身展开）、目标数、附带状态（如定身类人→麻痹）和专注，所有字段都可以改。之后在地图上显示射程圈和范围模板：点选目标（限射程和数量），或移动鼠标放置范围（范围内的生物自动选中，可再点击排除 / 加入），回车结算。选目标时右键轻点撤销上一步（点选的目标去掉最后选的那个，放好的范围回到重新放置，自由路径撤掉上一个点），没有可撤的时候右键就取消这次行动；右键拖动仍是平移地图。服务器为每个目标掷骰：攻击对 AC（含掩护、按状态自动优劣势、麻痹 / 昏迷近身重击、重击伤害骰翻倍），豁免对 DC（读取目标卡上的豁免加值，掩护加到敏捷豁免，麻痹等状态力量 / 敏捷豁免自动失败），按卡上的抗性 / 免疫 / 易伤调整伤害，直接扣血 / 回血 / 给临时生命 / 挂状态，施放者自动进入专注，受伤的专注者提示豁免 DC；结果逐个目标写进记录
- **判定修正（特性 / 装备 / 增益）**: 结算时自动考虑目标身上的修正，并在记录里注明用了哪条：反射闪避（敏捷豁免半伤效果成功无伤、失败半伤，失能无效）、魔法抗性（对抗法术的豁免优势）、危机感应、侏儒狡黠、矮人体魄、妖精血统、勇气、守护灵光（豁免 + 魅力调整值）、勇气灵光（免疫恐慌）、狂暴（钝穿挥抗性、力量豁免优势）、石化（全抗、免疫毒素），以及怪物卡「免疫」栏里的状态免疫（挂不上对应状态）、人物卡「优势」栏里的豁免优势；传奇抗性的怪物豁免失败时会提示 GM。这些按角色卡上特性 / 动作的名字自动识别，显示在角色卡的「判定修正」一栏，识别错了或卡上数值已经算进去了可以「停用」。装备、法术等其他来源在同一栏手动添加：豁免加值（如防护斗篷 +1）、豁免优势（总是 / 对抗法术 / 避免某状态）、伤害抗性 / 免疫 / 易伤（可选「物理」= 钝穿挥、「全部」）、状态免疫、额外 AC（抗性 / 免疫可勾「仅非魔法」）
- **多段伤害与魔法**: 一次行动可以有多种伤害（行动框的「附加伤害」：和主伤害一样是「骰子 + 伤害类型下拉框」，默认空着，最多加到 4 段，如武器 1d8+3 穿刺外加 2d6 火焰、冰风暴的钝击 + 寒冷；下面的「快捷」-5 / -1 / +1 / +5 / +1d4 / +1d6 / +1d8 / +1d10 / +1d20 加到最近点过的伤害框，同面数的骰子自动合并），每段按自己的类型分别结算抗性 / 免疫 / 易伤，暴击一起翻倍；说明文字里的「外加…点毒素伤害」「…钝击伤害和…寒冷伤害」会自动识别（「或」「改为」后面的替代说法不算）。行动框的「魔法」勾选（法术总是魔法，+1 武器、带「魔法武器」特质的怪物默认勾上）决定能否无视「非魔法攻击造成的钝击、穿刺和挥砍伤害」这类抗性；「除力场、心灵外的所有伤害」这种写法也会正确处理。魔法抗性按特质正文识别范围：只对某学派（如「对抗附魔学派法术」）、只对某些属性的豁免、只对某种状态，或泛用的「法术和其他魔法效应」
- **被命中后的反应**: 攻击结算后，记录里被命中的目标旁会出现反应按钮（只有 GM 和棋子主人看得到，角色卡上要有对应特性 / 法术，每次攻击限用一次）：「拨挡攻击」（这次攻击的伤害里有钝击 / 穿刺 / 挥砍时，减少整次攻击的伤害——包括其中的魔法部分——1d10 + 敏捷调整值 + 武僧等级）、「直觉闪避」（伤害减半）、「盾牌术」（AC +5 重新判定，不再命中则伤害和附带状态作废，自动扣一环法术位）。反应按减伤重新结算：从这次攻击之前的状态出发，用减少后的伤害重新扣一次——临时生命值重新先吸收，倒地 / 当场死亡 / 0 生命值时的死亡豁免失败按新的伤害重新判定，因倒地中断的专注会恢复，并注明新的专注豁免 DC；攻击之后发生的治疗等变化保留。记录里另起一条，GM 可以撤销（攻击前的状态只在内存里保留最近 30 次，服务器重启后的旧攻击按把生命值加回处理）
- **法术默认伤害与升环**: 从角色卡施放法术时自动填好默认伤害骰和伤害类型（如月华之光 2d10 光耀、治愈真言 2d4+施法调整值）。可以升环的法术在行动框里直接选「环阶」，伤害 / 治疗骰按「每高一环 +XdY」自动改好（月华之光 3 环 = 3d10），魔法飞弹这类按环多出目标的也会加目标数；下拉框里显示每一环剩余的法术位，勾选「消耗法术位」时施放会自动扣掉。戏法按角色等级自动强化（如 11 级冷冻射线 3d8）。伤害类型改为下拉框选择
- **本地规则库**: 服务器启动时读入 `data/5e`（按出处整理的不全书数据：法术、职业特性、子职特性、种族与背景、专长、装备、魔法物品，见 [data/5e/README.md](data/5e/README.md)）。从角色卡施放法术时先查本地规则库，按结构化数据直接填好行动框：攻击 / 豁免 / 治疗 / 临时生命、伤害骰和类型（只有说明里用「+」连在一起的才算附加伤害，「光耀或黯蚀」这类二选一只取第一个）、成功减半、射程、范围形状和大小、是否专注、施法时间对应的消耗、升环（含每环 +5 这类固定加值）、戏法强化、附带状态，行动框里注明数据出处；不用联网，也不靠文字猜。查不到的法术照旧在线查不全书。每回合限一次、回合结束重复豁免、回合开始伤害这些结构化数据里没有的细节，仍从说明文字补上
- **自定义范围（墙类法术）**: 范围新增「直墙」（点两下定起点和方向，长度不超过上限）、「自由形状墙」（连续点出拐点，总长不超过上限；原地再点一下 / Enter / 「完成形状」结束）、「环形墙」（直径 + 厚度）。法术文字里的「长至多 X 尺」「厚 X 尺」「可塑造为任意形状 / 连续路径」「直径至多 X 尺的环形墙」「十块 10 尺×10 尺的嵌板」会自动识别（如风墙术 = 总长 50 尺、厚 1 尺的自由形状墙，火墙术可在直墙和环形墙之间切换）。放置时操作条上可以随时用 − / ＋ 调整大小和宽 / 厚度；画错了可以「↶ 撤销上一点」（Backspace）或「重画」。墙经过的生物（判定圈碰到墙的厚度范围）自动选为目标
- **先画好再决定**: 范围放好后不会自动结算，由玩家点「结算」；持续性的范围还可以点「只放置，不结算」——只施法（扣法术位、进入专注）并把区域留在地图上，之后需要时再对区域内结算。移动地图上的持续区域（如月华之光）后，会提示「是否对新位置里的生物结算」，可增减目标后结算或选择不结算
- **持续区域**: 持续性的范围法术（月华之光、灵体卫士、匕首之云等，带专注或持续时间）结算后在地图上保留半透明区域（行动框里可取消勾选）：可以拖动移动；以自身为中心的光环跟着施放者走；选中区域后点「⚡ 对区域内结算」会自动选好区域内的生物再结算一次（生物进入或在其中结束回合时用，不会再扣法术位）；施放者失去专注后区域自动移除，开始新的专注时旧的专注区域也会移除。区域只有点到边框才算选中，点中间当作空地；选中之后（或在右上角状态栏点专注的法术名）在区域里任意一点都能拖动它。每回合限一次的效果（月华之光、灵体卫士等，法术说明里写「每回合只……一次」时自动勾选，行动框和区域属性里可改）会记录本回合已结算过的生物，再结算时自动排除并在操作条上列出；换回合后重置，战斗外不限制
- **GM 撤销结算**: 记录里每次行动结算旁边有 ↶ 按钮（仅 GM），撤销后目标的生命值、临时生命、状态和死亡豁免恢复到结算前（保留最近 30 次）
- **生命值记录**: 手动改血（属性面板、±、快捷菜单、全体伤害 / 治疗、长休、撤销）都会写进记录，如「调整生命值：哥布林 −7」；玩家看 GM 怪物时只显示变化量，自己的角色显示「24 → 17」；被隐藏单位的变化只给 GM（和该角色的玩家）看
- **回合开始位置**: 轮到某个单位时，结束回合前地图上一直用黄色虚线圈标出它回合开始时的位置，并连线到当前位置
- **怪物一键部署**: GM 在「📜 角色 → 不全书图鉴」里搜索时，结果上方多一栏「👹 怪物」：数据来自 5e.kiwee.top（Owlbear 怪物图鉴插件用的中文 5etools），点「部署」就把怪物放到当前镜头中心（默认对玩家隐藏），自动建好怪物卡、用怪物图鉴的棋子头像，并把立绘显示在怪物卡上；房间里已有同一只怪的卡时直接沿用、自动编号。按 2024 规则以 2025 怪物图鉴为准，不收 2014 版核心书和被替代的旧怪物书，同名怪物只列一条。怪物数据缓存在服务器的 `tabletop_dir/kiwee/`（7 天刷新），服务器需要能访问 5e.kiwee.top
- **角色状态栏**: 画面右上角显示自己控制的角色（GM：选中的棋子，没选时显示当前行动者）的生命值、增益 / 减益状态（绿色增益、红色减益，悬停看规则和剩余轮数）、正在专注的法术和留在地图上的区域；点名字选中并居中，点法术名选中区域，✕ 结束专注。可以收起
- **历史记录浮窗**: 掷骰、行动、聊天记录不再放在侧栏，而是画布上的独立浮窗（默认右下角），切到其他侧栏页也一直可见；拖标题栏移动、右下角调大小、▾ 收起，双击标题恢复默认位置，位置和大小记在本机
- **先攻条**: 画面底部的先攻条所有人可见，默认带棋子立绘（右侧 ≡ / 🖼 切换简化版，记在本机），拖左侧 ⠿ 可以移动（双击恢复默认位置），从当前行动者开始排列，点击定位到棋子，GM 双击可直接切到该单位的回合。回合切换时镜头自动移到当前行动者（设置里可关），下一位轮到自己时会提前提醒；当前行动者被移出先攻或删除时，「下一位」仍按原来的位置继续。战斗中 GM 从角色卡 / 怪物卡放下的单位自动掷先攻加入。GM 可以点右下角「📍 全员看这里」把所有人的镜头移到自己正在看的位置。GM 可以把单位「在玩家的先攻条中隐藏」（战斗栏 👁 或棋子属性），GM 控制的单位处于「躲藏」状态时也自动对玩家隐藏——玩家端根本收不到这些单位的先攻数据，轮到它们时只显示「隐藏单位」。GM 可直接改先攻值、用 ▲▼ 调整顺序、▶ 跳到任意单位的回合、调整轮数。设置里可选「加入先攻的单位默认在玩家的先攻条中隐藏」

- **访客昵称**: 门禁访客的昵称和他的登录令牌绑定，其他访客不能用同一个昵称冒充；令牌过期后昵称自动释放。访客刷新页面不用重新输入口令（只在当前标签页内有效）
- **隐藏与可见**: GM 勾选「对玩家隐藏」的棋子，控制它的玩家自己仍然看得到（半透明），其他玩家看不到；GM 从角色卡放下已分配给玩家的角色时不再默认隐藏。GM 的单位处于「躲藏」状态时，玩家的地图上也看不到它。玩家点不到、框选不到、搜不到迷雾里或视野外的棋子
- **行动日志**: 行动记录显示是哪个棋子出手（「狗头人武者 2 · 匕首」）；同一张怪物卡放了多个棋子时，从卡上发起行动默认用正在行动的那个（其次是选中的那个）。玩家只能用自己控制的棋子作为施放者
- **手机 / 触控板**: 窄屏上侧栏默认收起，打开角色卡、搜索结果时自动展开；触屏单指拖空白处平移地图（触屏没有中键，选择工具在触屏上仍是单指拖空白处平移），轻点不会挪动棋子；触控板双指滑动平移、双指捏合缩放。先攻条上的 🎥 可以开关「镜头跟随当前行动者」（玩家也能关）
- **GM 放置默认隐藏**: GM 从角色卡 / 怪物卡放置的棋子默认对玩家隐藏（在棋子属性里取消「对玩家隐藏」即可公开），设置里可以关闭这个默认
- **目标与命中判定**: 鼠标放在棋子上按 **T**（或属性面板「设为目标」）选择目标，地图上显示距离和掩护。从角色卡 / 怪物卡发起攻击检定时，确认框显示与目标的距离、是否在触及 / 射程内（远射程自动劣势，超出射程提示）、掩护（墙按 DMG 角对角规则：半身 +2 / 四分之三 +5 / 完全；中间隔着其他生物 = 半身），并由服务器对目标 AC（含掩护）结算命中 / 未命中 / 重击 / 大失败。GM 控制的棋子的 AC 不会发送给玩家
- **状态效果**: 在棋子属性面板里挂上 5e 状态（目盲、魅惑、力竭（可叠级）、恐慌、受擒、失能、隐形、麻痹、石化、中毒、倒地、束缚、震慑、昏迷）以及专注、祝福、灾祸、加速、闪避、狂暴等常用效果，也可自定义；可设持续轮数，在该棋子的回合结束时自动递减（所以「1 轮」会持续到它的下一个回合结束）、到期移除并写进记录。状态以图标显示在棋子上方。攻击检定会按双方状态自动给出优势 / 劣势（同时存在则抵消）、力竭调整值、祝福 / 灾祸骰，麻痹 / 昏迷的目标被 5 尺内命中自动算重击；专注中的棋子受伤时自动提醒专注豁免 DC
- **Boss 血条**: GM 在棋子属性里勾选「顶部大血条」，画面上方显示大血条（最多 3 个，点击定位）；玩家默认只看到比例，勾选「公开数值」后显示具体血量
- **全局搜索**: 顶栏搜索框（Ctrl+K）一次搜索本场景棋子、角色卡 / 怪物 / 物品、角色卡里的法术、状态说明，最后一项可直接去不全书搜索；方向键选择，回车打开
- **棋子资源**: 法术位、职业资源等按棋子记录（兼容 obr-suite 资源追踪），属性面板里点 −/+ 消耗或恢复；从角色卡放置棋子时自动生成法术位和特殊资源
- **绘制 / 法术范围**: 画笔、直线、矩形、圆形（显示半径）、锥形（5e 规则），实时显示距离；线宽可选「0.1 格」（按网格算）；右键轻点 = 撤销自己上一笔，右键拖动 = 平移；「清除绘制」点两次确认
- **迷雾**: GM 用矩形 / 多边形 / 笔刷遮盖或揭示，玩家端完全不透明；隐藏的棋子不会发送给玩家。笔刷 0.1 ~ 4 格；右键轻点 = 撤销上一笔（画多边形时回退上一个点），右键拖动 = 平移；「🗑 清除…」下拉一键删除全部揭示 / 全部遮盖 / 全部迷雾（再点红色按钮确认），只删某一块就切到「选择」点中它按 Delete
- **墙体 / 门窗 / 动态视野**: GM 用墙体工具（W）逐点画墙、窗、门（默认不吸附网格，靠近已有拐点会接上，按住 Alt 吸附半格；落点和到光标的预览线随鼠标实时显示，吸到已有拐点时落点变成实心；按住 Shift 锁定水平 / 竖直 / 45°；双击 / Enter 结束，右键或 Backspace 回退上一个点，只剩起点时取消；「▭ 矩形」「◯ 圆形」在地图上拖一下就画出闭合的墙 / 窗，Shift = 正方形 / 正圆，Alt = 吸附半格，适合围石头、树、柱子）。墙挡视线和移动，窗只挡移动，门关着时同墙、玩家可点击开关；门可以上锁（玩家看得见但打不开：画门时勾「🔒 上锁」，或 GM 在选择工具下 Alt+点击门切换，GM 视角锁着的门中间有个 🔒）；暗门只有 GM 看得见，玩家那边就是一面普通的墙、也打不开，GM 打开后玩家才看到一扇锁着的门并能通过。开启「动态视野」后，玩家只看得到自己棋子视线所及的地方（可设视野距离，如 60 尺），看过的区域保持半暗，视野外的敌人不显示；玩家拖动棋子穿墙会被挡回。导入 `.dd2vtt` / `.uvtt` 时会一并导入其中的墙体和门。墙体工具栏上「✖ 清空规划」= 清掉还没生成的东西（自动识别的预览、描过的段、没画完的折线），「🗑 清除…」下拉 = 一键删除本场景的全部墙 / 窗 / 门 / 暗门 / 全部（选好后点出现的红色按钮确认，Ctrl+Z 可撤销）。墙体「选择」模式下点在线上 = 选中两个拐点之间的那一段（黄色），Delete 只删这一段（折线自动断成两条，闭合的框会变成一条开口的线），属性面板里也能把这一段单独改成墙 / 窗 / 门 / 暗门——自动生成的整条墙要开门洞、改窗户不用先拆。一次删 4 个以上物件时按两次 Delete 确认
- **自动画墙**: 墙体工具里的「🪄 自动」，按地图图片识别墙，先显示青色虚线预览，滑块实时调整，满意了点「生成墙体」（Ctrl+Z 可整批撤销，Esc 或右键轻点取消，Enter 生成）。「🧵 沿墙延伸」：沿着墙中间描一小段（半格到一两格），松手后自动顺着**同一种墙**往两头追——先学这段墙横截面的样子，算出整张图上每个位置「像不像这种墙」，再每次往前看 1.5 格找一条最省力的路（最短路，类似遥感里的半自动道路追踪），拐角、弧形墙会跟着拐，壁灯、柱子、窗框这类半格左右的遮挡会跨过去，门洞、墙走到头就停；勾着「跟随岔路」时碰到 T 字口 / 十字口会把同一种墙的岔路也追出来，追回到描过的墙会自动接上（房间绕一圈会闭合）。追断了就在断头外面的墙上**单击**，会从最近的预览线端点沿墙接过去（智能剪刀）。可以连描多段，后描的不会重复画先描出来的墙；右键撤销上一步，「宽松度」越大追得越远（也越容易追出墙外）。薄隔墙、木墙这类和描的那段长得不一样的墙不会被连上，需要另外描一段。适合建筑类地图；描的那段跨过了壁炉、门、拐角，或者是洞穴岩壁这种不规则的边时会提示换一段描（洞穴用「点地板」）。「识别墙体」（默认）：拖一个框，直接找出墙本身——两侧有清楚边缘、粗细一致的带子——沿墙中间画一条横平竖直的线，共线的自动接上、拐角和丁字口自动接到一起，孤立的短段（家具、楼梯）去掉，适合写实 / 彩色地图（墙比地板亮或暗都行），「灵敏度」越高找到的墙越多，也更容易把长桌、地板缝当成墙；只认横平竖直的墙，斜墙、圆墙用「识别线条」或手画。「识别线条」：在地图上拖一个框，深色的墙线变成墙（自动忽略网格线等细线、保留门洞缺口），大片的深色（写实地图房间外的黑色虚空）只沿边缘围墙；「点地板」：拖框后点一块地面，沿它和周围的分界围墙，适合洞穴、岩浆等不规则的地图——强边缘（岩石边、墙的轮廓线）和颜色差异都会挡住，比半格窄的缝过不去，所以不会顺着小缺口或门洞漏出去；也可以反过来点墙外的虚空 / 岩浆；可以连点多处，右键撤销上一个点，结果只取大致轮廓——像手画那样沿边缘拉直线，2×2 格以内的障碍（骨堆、家具）不围，纹理很杂没填满的地方也会连起来；还有支洞没围到就再点一下那里，「精简」越大线越直。框和已经画过的墙重合的部分自动跳过，同一块地方反复识别不会画出重复的墙。线稿类地图几乎不用修，写实地图通常要删几段多余的；门窗不会自动识别，生成后用「门」「窗」补画。Dungeondraft 等导出的 `.dd2vtt` 自带精确墙体，优先用它
- **墙体编辑**: 墙体工具「选择」模式下：拖动拐点移动（和它重合的其他墙的拐点一起动，靠近别的拐点会吸上去接好；按住 Alt 只拖这一条、不吸附），双击线段加拐点、双击拐点删掉（只剩一段时删掉整段墙），右键中间的拐点在此断开成两段。拖框（或 Shift+拖动）框选碰到框的所有墙，选中多段后可以一起「改为」墙 / 窗 / 门 / 暗门、「合并相连」（首尾相接的同类墙合并成一条折线），「拆成单段」把折线拆开，方便单独删掉某一段或改成门。这些操作都能 Ctrl+Z 一步撤销
- **找门洞**: 墙体工具里的「🚪 找门洞」，找出墙线之间不超过设定宽度（默认 1.5 格）的缺口——两段墙头相对的缺口，以及墙头正对另一面墙的缺口（拐角、丁字口的门）——用黄色虚线标出。点一下补成门（也可选窗、暗门，或「墙」把缺口封上），「全部补上」一次补完（Ctrl+Z 整批撤销），Shift+点忽略不是门的缺口。只认得开放的墙线之间的缺口；「点地板」生成的闭合房间轮廓需要在「选择」里加拐点、拆段后把门洞那段改成门
- **房间笔记**: GM 工具栏的 📌（快捷键 B），在地图上单击放置编号笔记（自动编号 1、2、3…，可改成 A3 之类，可换颜色），属性里写标题、GM 笔记（怪物、陷阱、宝藏、剧情）和朗读 / 给玩家看的文字。笔记只有 GM 看得到（服务器从不发给玩家），「玩家视角」预览时隐藏；可拖动、复制、Ctrl+Z。侧栏「📌 团本」列出本场景所有笔记，可搜索，点一下跳到那个房间；笔记里的「📢 展示给玩家」把朗读文字做成讲义推送
- **讲义 / 线索**: GM 在侧栏「📌 团本 → 讲义」里新建讲义：标题、文字、图片（上传，或从资产库选），发给全体或指定玩家。「只保存」先存着，跑团时点「展示」弹到玩家屏幕上；上传的讲义图片不进资产库，展示之前玩家收不到也看不到。玩家的侧栏「📌 线索」里保留收到的所有讲义，随时点开再看（大图可在新标签页打开原图），有新讲义时标签上有红点。只发给部分玩家的讲义，记录里的「展示了讲义」也只有 GM 和收件人看得到。讲义随房间一起导出 / 导入
- **按房间揭示迷雾**: 迷雾工具里的「🏠 房间」，鼠标移到房间里会用虚线预览沿墙围出的区域，单击就把整个房间揭开（选「遮盖」则盖上），Ctrl+Z 撤销。墙、门、窗、暗门都算房间的边界；墙有缺口（或点在房间外面）时会提示，可以先用「🚪 找门洞」补门。场景里要先有墙
- **触发区域**: 📌 工具切到「⚠ 触发区域」，在地图上拖一个矩形。可以写名称、提醒 GM 的内容和效果（如「DC 13 敏捷豁免，失败受到 2d10 穿刺伤害，成功减半」），可选「只触发一次」「停用」。玩家控制的棋子（中心点）走进区域时，服务器在记录里只给 GM 提示并弹出通知，提示后面有「定位」和「⚡ 结算」：结算会按效果文字打开行动框并预先选好走进去的棋子。只触发一次的区域触发后变灰，可「重新启用」。触发区域只有 GM 看得到
- **遭遇预设与难度**: 选中一个或多个 GM 棋子，属性面板「遭遇 → 编入」起个名字。「📌 团本 → 遭遇」按 2024 城主指南的经验预算（队伍等级读自场景里玩家棋子关联的人物卡，没有时用房间里已分配的人物卡；怪物经验按怪物卡的 CR）显示每个遭遇是低 / 中 / 高 / 超出高难度，并可「开战」（全部现身、掷先攻；没在战斗时连同玩家一起「准备战斗」开战）、「选中」、一键对玩家隐藏 / 显示、解散。遭遇名不会发给玩家
- **进入场景时**: 「⚙ 设置」里的「进入这个场景时」：切换到当前场景时自动播放某首音乐（或停止音乐）、弹出某份讲义、把所有人的镜头移到「开场镜头」（用 GM 当时的视角设定）。黑暗环境、动态视野本来就是每个场景各自的设置
- **随机表**: 「📌 团本 → 随机表」新建表：每行一个条目，可以写「1-3 [[1d4]] 只狼」这样的范围（骰子可指定，如 1d20、2d6，留空按最大值 1dN），不写范围则每行概率相同；条目里的 [[2d6]] 会掷出结果。🎲 公开掷、「暗」只有 GM 看得到，由服务器掷骰，结果写进记录。随机表只发给 GM，随房间一起导出
- **角色跨地图**: 队伍角色（玩家角色卡和它们的随从）放到另一张地图时，自动沿用它在上一张地图（最近离开的场景优先）那枚棋子的血量、临时 HP、状态、资源、头像、体型和改过的名字，按两张图的格子大小缩放；跟着它的光环区域、跟随的棋子也一起带过来。位置、先攻、本回合的动作和移动不带；原来对玩家公开就保持公开。别的地图上的人施加的「到他回合为止」状态和擒抱不带。玩家只能带自己的角色
- **场景模板**: 「🗺 场景」里每个场景的「导出」把这个场景（地图、墙、门、迷雾、笔记、触发区域、棋子、进入场景时的设置）连同棋子关联的角色卡 / 怪物卡和用到的图片打包成 zip；在任何房间的「导入场景」里导入，成为一个新场景（战斗状态不会带过去，房间里已有的同一张卡沿用）。整个房间的备份 zip 在这里导入会建成一个新房间
- **战斗提示（规则见 [docs/战斗规则.md](docs/战斗规则.md)）**: 按 2024 规则在合适的时机提示、一键结算，但不拦任何操作，「⚙ 设置 → 战斗提示」里四类都能单独关掉：
  - **动作经济**：先攻条上显示当前行动者的「动作 / 附赠 / 反应」，点一下手动勾选 / 取消；结算行动时按行动框里的「消耗」（按说明文字自动判断附赠动作 / 反应）自动勾上，用过反应也会记上；轮到它时清零。同一回合第二次用法术位施法时提示 2024 的「一回合一个耗环法术」
  - **借机攻击**：战斗中拖动棋子，按实际路线判断有没有离开敌对生物的触及范围（触及读卡上近战攻击的「触及 X 尺」，可在棋子属性里填），提示 GM 和对方控制者；「⚔ 借机攻击」用对方的近战攻击打开行动框，预选好目标、消耗设为反应。撤离、飞掠、对方已用反应 / 失能 / 看不见移动者、阵营为中立时不提示；阵营默认玩家 = 友方、GM = 敌方，可在棋子属性里改
  - **专注豁免**：受伤后记录里的「🎲 专注豁免」由服务器掷体质豁免（读卡上的豁免加值，算上判定修正、战争施法者优势、祝福 / 灾祸、力竭），失败自动结束专注
  - **回合开始 / 结束**：轮到某单位时去掉它的「闪避」，回合结束时去掉「撤离」（新增状态）；状态可以带「回合结束时重复豁免」和「回合开始时受到伤害」（状态旁的 ⏱，或行动框里的「回合结束重复豁免」「回合开始伤害」，会从法术说明自动识别），到点时记录里给 GM 和控制者「🎲 豁免」（成功自动去掉状态）/「🔥 结算伤害」按钮
  - **传奇与充能**：关联怪物卡的棋子在开战时自动加上「传奇动作」「传奇抗性」「充能·X」资源；每个单位回合结束时提示哪些怪物还能用传奇动作（「用一次」扣一次并打开怪物卡），轮到怪物时传奇动作恢复满、用过的充能能力自动掷 d6；怪物豁免失败时出现「传奇抗性」按钮，扣一次并按豁免成功重新结算伤害和状态
  - **多重攻击**：怪物卡「多重攻击」旁的 ⚡ 列出这次要做的攻击和次数（如「一次啮咬和两次爪击」），点一次打开一次攻击
  - **武器精通（2024）**：要角色精通了这把武器才判定——「已精通」默认按角色卡有没有「武器精通」特性勾选，可手动改并记在角色卡上，不勾就不出精通按钮。行动框的「武器精通」读武器上写的精通（没写但角色有「武器精通」特性时从规则库武器表补），攻击后记录里给出手的人对应按钮：侵扰（对该目标下次攻击优势，用后自动去掉）、削弱（目标下次攻击劣势）、失衡（体质豁免，失败倒地）、推离 10 尺、缓速 −10 尺、横扫（再打开一次攻击）、失手时擦掠伤害
  - **徒手打击：擒抱 / 推撞**：属性面板「徒手」一行有 👊 打击、🤼 擒抱、推撞；擒抱 / 推撞是目标的「力量或敏捷（取高）」豁免，DC = 8 + 力量调整值 + 熟练加值；受擒状态记下 DC，状态旁「挣脱」由服务器掷运动 / 特技（取高）；推撞可选倒地，或结算后「推开 5 尺」
  - **职业特性一键**：属性面板「职业」一行有 狂暴 / 结束狂暴、回气、动作如潮、诗人激励（显示剩余次数，次数记在棋子资源里，没有时按等级表新建）；狂暴中近战攻击的行动框自动勾上「狂暴伤害 +N」；游荡者命中后记录里有「偷袭 +Nd6」（重击翻倍，每回合一次，看不出满足条件时带「？」由 GM 判断）
  - **战士 / 符文骑士 / 化兽者**：角色卡可以填子职；额外攻击按攻击动作计数；战术思维、战术转进、不屈（服务器重掷豁免 + 战士等级）、究明攻击；巨武器战斗（伤害骰 1、2 按 3）；巨人之力（棋子放大、力量豁免优势、每回合一次加伤）、火焰 / 云雾 / 寒霜 / 岩石 / 山丘 / 风暴符文、符文之盾（攻击者重掷）、云雾符文（把命中改给别人）；化兽的临时生命和迅捷加速
  - **武僧 / 四象武者**：功力点（棋子资源）和武艺骰；武艺附赠打击、疾风连击（攻击条逐次结算）、坚强防御、疾步如风（疾走时速度翻倍）、运转周天、明镜止水、无懈可击；拨挡攻击减到 0 后「反弹」、13 级拨挡能量；震慑拳、圆融自在（服务器重掷豁免）、返本还元提示；元素同调（触及 +10、推拉 10 尺）、元素爆破拳、四象神通
  - **牧师·战争领域 / 龙裔**：引导神力（神圣火花伤害 / 治疗、驱散亡灵 + 灼净亡灵）、战争祭司附赠攻击、导引打击（失手 +10，服务器补结算伤害）、战神祝福（免费不专注）、神圣干预、神圣打击、强力施法；吐息武器（按龙色定伤害类型）、龙族飞翼
  - **德鲁伊·星辰结社**：荒野变形（临时生命）、荒野伙伴（打开新建随从）、荒野复苏、原力蛮击；星图免费光导箭、星耀形态（射手光箭、圣杯额外治疗、巨龙座专注豁免至少按 10）、宇宙预兆、闪烁星座换星座、灿若繁星抗性
  - **法师·预言师**：奥术回想自动恢复法术位；预兆由服务器掷并记在棋子上，记录里一键替换豁免 / 攻击的 d20 并自动重新结算；专业预言返还法术位；天眼通、招牌法术
  - **奇械师·魔炮师 / 战俑**：魔能炮台快捷新建、奥法火器 +1d8、灵光一闪（服务器重判豁免）、要塞阵地半身掩护；战俑毒素抗性和对中毒的豁免优势
  - **手动豁免**：属性面板「自动掷豁免」不勾时，需要豁免时记录里提示要掷什么属性、DC 多少、成败各会怎样（玩家弹出提醒），玩家点「掷豁免」由服务器当场掷，或自己掷骰后点「成功 / 失败」，伤害和状态照样自动结算
  - **判定细节**：敌我按玩家角色卡判断（GM 代管的队友也算友方，玩家能看到队友准确血量 / AC）；先攻同值比加值；范围不选尸体、点选优先活人；2024 怪物卡「X 尺内的生物」光环识别；状态可持续到施放者下回合结束 / 开始；用了充能能力自动扣充能；区域在回合开始 / 结束时给结算按钮；借机攻击按离开前的位置算；行动框提醒本回合动作 / 附赠 / 反应 / 法术位已用；龙裔血统抗性；完整说明见 docs/战斗规则.md 第 14 节
  - **战斗自动化分类开关**：「⚙ 设置 → 战斗自动化」按判定与结算（特性自动识别、状态优劣势、自动掩护）、回合流程、战斗提示、职业特性（总开关 + 分职业）、专长与种族分组，每一项都能单独关掉；完整清单见 docs/战斗规则.md 第 13 节
  - **反应法术**：法术结算后，附近（60 尺内）有「法术反制」、反应没用过的单位旁出现「法术反制」按钮，由服务器掷施法者的体质豁免对抗反制者的法术 DC，失败则撤销这次结算并退回施法者用掉的法术位；受伤的目标有「炼狱叱喝」时可一键反击伤害来源（按规则库填好行动框、预选目标、消耗反应），有「吸收元素」且受到元素伤害时可一键把那部分伤害减半并获得到下回合开始的抗性；羽落术等照常从角色卡施放
  - **专长（2024）**：重型武器的行动框里有「巨武器大师 +熟练加值」勾选；神射手 / 强弩专家 / 擒抱者在确认目标时自动修正掩护和优劣势并写进记录；记录里给出顺势斩、长柄打击、哨兵借机 / 阻拦、招架（防御式决斗）、介入盾牌、拦截按钮（后三个由服务器按减伤重新结算）；撤离也会提示哨兵借机，进入长柄武器大师的触及会提示反击，战地施法者可一键用法术代替借机攻击；巫师杀手让专注豁免劣势；属性面板「🍀 幸运」扣幸运点，下一次攻击或豁免自动优势
  - **随从 / 召唤物**：角色卡新增「随从」类，设「主控」后法术攻击、DC、熟练加值跟随主控；卡上文字的【法术DC】【奇械师等级×5】【奇械师9级：3d8｜2d8】之类按主控实时换算；内置魔能炮台模板（护卫的临时生命只掷骰、不自动加）；随从卡可编辑，可自定义棋子图标（资产库选或上传），棋子放在主控旁边，倒下即摧毁；行动方式可选「跟随主控」（不进先攻条，挂在主控后面，主控回合内自由移动和指挥，回合开始 / 结束效果随主控一起结算，消耗记在主控身上）或「独立先攻」
  - 行动附加的状态会带上「回合结束重复豁免」「回合开始伤害」「擒抱 DC」（服务器校验后保留）；豁免类行动可以不填伤害和状态，只让目标掷豁免
- **角色卡（Excel / JSON 导入）**: 玩家在「📜 角色」里导入「DND 5E2024 人物卡」Excel（.xlsx，读取「主要」工作表），或 obr-suite 角色卡的 `data.json`（含法术全文，点法术直接显示效果），自动生成角色卡：属性检定 / 豁免、18 项技能、武器命中与伤害、法术攻击与 DC、法术位、特殊资源、特性专长，全部点击即掷（会使用骰子栏的优势 / 劣势、暗骰开关）；可放置关联棋子，升级后重新导入同名角色即覆盖更新

- **选择工具（箭头，V）与拖图工具（✋，H）**: 选择工具：左键点棋子或区域边框 = 选中，拖动棋子 = 移动；左键拖空地 = 框选（Shift = 加选）；点空地取消选择；中键拖动（或空格 + 左键）= 平移地图。拖图工具：左键拖哪里都只平移地图，不会误移棋子。两个工具的右键用法相同：右键按住拖动 = 指示（所有人能看到轨迹），右键轻点空地 = 标记位置，右键轻点棋子 = 快捷菜单（伤害 / 治疗、添加状态、设为目标、掷先攻、以它行动、查看角色卡，GM 还有隐藏 / 锁定 / 删除）。触屏：长按棋子 = 快捷菜单，长按地图 = 标记
- **右键菜单 / 删除**: 右键轻点（触屏长按）任何棋子、绘制、文字、区域、笔记、触发区域都会弹出菜单，里面可以删除（GM 还能隐藏、锁定，绘制可以移到最上 / 最下层）；别人画的东西只显示「不能修改」。框选多个后，右键其中任意一个或选区范围里的空地 = 批量菜单：删除这 N 个（超过 3 个或有在先攻里的要再点一次确认）、全部隐藏 / 显示、全部锁定 / 解锁。选中后按 Delete / Backspace 也能删，Ctrl+Z 撤销
- **绘制缩放 / 旋转**: 选中一个绘制（画笔、直线、矩形、圆、锥形、多边形、文字）后和棋子一样：拖四角等比缩放（线宽一起缩放，Shift 按 0.25 倍吸附），拖顶上的圆点旋转（吸附 15°，Alt 自由；文字只能缩放）。转过的矩形会变成四边形。持续区域不能这样改
- **规则版本**: 统一按 D&D 5e 2024 版规则。法术说明只查 2024 玩家手册（2024 版没有收录的才查 XGE / TCE），不查 2014 玩家手册；不全书搜索结果不显示 2014 版的玩家手册、怪物图鉴、城主指南

- **页内确认框**: 房间里所有的确认和输入（场景改名 / 删除、写文字、传送门、移除图片、开始 / 结束战斗、撤销结算、结束专注、短休、状态回合效果、挣脱擒抱、自定义状态、删除 / 重新导入角色卡、删除讲义 / 随机表、解散遭遇、删除房间、清空记录、保存快捷骰、邀请链接）都改用页面里的对话框，不再用浏览器弹窗，内嵌浏览器里也能用；右键菜单删除先攻里的棋子改为再点一次确认
- **场景顺序 / 收着的地图**: 场景列表每行有 ↑ ↓ 调顺序；资产库（GM）在当前地图上标「当前地图」，换图时跟着旧图收起来的东西标「📦 N」（点「作地图」换回去就恢复），设置里的地图信息也会提示这个场景还有几张图收着东西
- **暗门**: 墙体工具里的「暗门」，GM 打开前对玩家来说就是一堵普通墙（数据里也看不出），打开后才能通行
- **黑暗与光源**: 设置里勾选「黑暗环境」后（配合动态视野），玩家只看得见被光源照到、或在自己黑暗视觉（棋子「视野」距离）范围内的地方，明亮光照完全可见、微光处半暗。棋子属性「光源」可填明亮 / 微光半径，或选火把、提灯等预设
- **传送门**: GM 在棋子属性里勾选「是传送门」并填标签，同标签的传送门互通。把棋子拖到传送门上松手，选好目的地后连同跟随它的棋子一起传送；对玩家隐藏的传送门可以当作单向出口
- **变身**: 棋子属性「变身」选一张怪物 / 角色卡（可选外观图片），换成它的 HP、AC、体型和名字；「恢复」逐层退回原形态
- **短休**: 关联角色卡的棋子点「短休」，选择花费几个生命骰，由服务器掷骰回血（加体质调整值）并扣除卡上的生命骰
- **准备 / 伏击 / 时间停止**: 战斗栏里「准备」「伏击」会给还没掷的单位掷先攻，全员显示横幅后开战（属性面板「自动掷：先攻」不勾的角色不替它掷，提示玩家自己点 🎲 掷（可选普通 / 优势 / 劣势），都掷完后 GM 再点「开始战斗」；先攻显示为「骰值 + 加值 = 总值」）；右下角「⏸ 时间停止」让玩家暂时无法操作地图（只能平移缩放），服务器同样拒绝玩家的改动
- **共享背景音乐**: GM 在设置里上传 MP3 / OGG / WAV / M4A 并播放，所有人同步，每个人在画面右上角单独调音量或静音
- **玩家权限**: 设置里可以分别关闭玩家放置棋子、绘制、拖动别人未锁定的棋子、开关门（服务器强制执行）
- **骰子**: 服务端掷骰防作弊，支持 `2d20kh1+5`、`4d6dl1`、`3d6!`、`d%`，以及重骰一次 `2d6r<=2`（巨武器战斗）、单骰保底 / 封顶 `1d20mi10`（可靠才能）/ `1d6ma4` 等表达式；记录里自己的掷骰可以点 ↻ 用同样的表达式再掷，优势/劣势、暗骰（仅自己和 GM 可见）、快捷骰、聊天中 `/r 1d20+3`、`/gr` 暗骰。骰子栏有常用说明（先攻、攻击、伤害、豁免…）、修正值快捷按钮、常用组合，以及「我的角色」一行（先攻、察觉、隐匿、各武器命中 / 伤害）
- **掷骰确认**: 角色卡、怪物卡、我的角色和快捷骰上的掷骰会先弹出确认框，可选普通 / 优势 / 劣势、调整值、祝福 +1d4 / 灾祸 −1d4、伤害暴击（骰子翻倍）、暗骰，并预览最终表达式；Shift+点击直接掷骰。「将投掷」的公式可以直接改（如加一个 +1d6），改过之后优势 / 劣势、调整值、祝福 / 灾祸、暴击翻倍这些按钮仍然在改过的公式上生效
- **法术速查**: 角色卡上的法术按环阶直接到不全书的法术详述（2024 玩家手册 → XGE → TCE → 2014 玩家手册）里找到并显示效果，法术里的骰子也能点击掷骰；译名略有差异（如「弹射 / 弹射术」）也能匹配
- **备份**: GM 可把整个房间（场景 + 棋子 + 图片）导出为 zip，在任意部署了本站的服务器上「导入房间」恢复
- **导入 Owlbear Rodeo（.ob2）**: 在大厅「导入房间」直接选择 Owlbear Rodeo 2 导出的 `.ob2` 文件，整个导出变成一个房间：所有场景、地图、棋子（位置、大小、名字、HP/AC、隐藏状态）、绘制、迷雾都会保留；Smoke & Spectre 的视线墙和门变成墙体 / 门，视野距离变成棋子视野；怪物图鉴插件里的怪物数据（不全书翻译）变成可点击掷骰的怪物卡并关联棋子；obr-suite 的 AC、先攻（含当前轮次和行动者）、资源追踪、状态追踪（含剩余轮数）、Boss 血条一并导入，其他插件数据原样保存在棋子上。导出文件里只是外链的图片（Owlbear 自带地图、kiwee 怪物头像）和 obr-suite 角色卡（存在 obr.dnd.center）会在导入时由服务器下载保存，所以要趁它们还能访问时导入；同一角色上传过多次时只保留最新的一张，并关联到所有绑定过它的棋子。角色卡下载失败时，之后玩家导入同名的 Excel / JSON 人物卡，也会自动关联到原来绑定的棋子并归该玩家控制。场景测距按实际长度导入（Owlbear 默认斜向不额外计费），可在设置里改为按格子计数

数据目录由 `tabletop_dir` 配置（默认 `../userdata/tabletop`）：`rooms/*.json` 为房间数据（每 2 秒自动保存），`assets/` 为上传的图片。实时同步使用 SSE，若前面有 Nginx 反向代理，请确保 `/api/tabletop/events` 不被缓冲（后端已发送 `X-Accel-Buffering: no`），并适当调大 `proxy_read_timeout`。

## 配置说明

程序启动时按优先级加载配置：**`config.json` > 环境变量 > 默认值**。首次启动若目录下无 `config.json`，会自动创建含默认值的配置文件。

参照 `backend/config.example.json` 编辑 `config.json`：

| 配置项 | 默认值 | 说明 |
|--------|--------|------|
| `server_addr` | `:80` | Go 后端监听地址 |
| `zlm_base_url` | `http://47.96.99.181:8080` | ZLMediaKit 服务器地址 |
| `zlm_secret` | `035c73f7-...` | ZLM API 密钥 |
| `admin_password` | `114514` | 门禁共享口令 |
| `db_path` | `./data.db` | SQLite 数据库文件路径 |
| `static_dir` | `../www` | 前端静态资源目录 |
| `token_expiry` | `72h` | Token 有效期，支持 Go duration 格式（`72h`、`2h30m`）或纯秒数（`259200`） |
| `download_dir` | `../userdata/download` | 云盘文件存储目录 |
| `game_dir` | `../game` | 游戏文件目录 |
| `video_dir` | `../userdata/videos` | VOD 视频文件目录 |
| `cloud_upload_min_role` | `user` | 云盘上传最低角色：`admin`（仅管理员）、`user`（注册用户及以上）、`door`（所有人含游客） |
| `rules_dir` | `../data/5e` | 本地规则库目录（按出处整理的不全书数据），不存在时规则库停用，施法回到在线查不全书 |
| `tabletop_dir` | `../userdata/tabletop` | 跑团桌面数据目录（房间 JSON + 图片资产）；导入 Owlbear `.ob2` 时服务器需要能访问 `images.owlbear.rodeo`、`5e.kiwee.top` 和 `obr.dnd.center` 以下载外链图片和角色卡 |

环境变量名称为配置项的蛇形大写形式（如 `SERVER_ADDR`、`CLOUD_UPLOAD_MIN_ROLE`），可覆盖配置文件中的值。

> 管理员账号 `admin` / `krusgaltn` 在首次启动时写入数据库，后续启动不会重复创建。如需重置，删除 `data.db` 后重启即可。

## 运行部署

### 前置条件

- Go 1.21+（已测试 1.26.1）
- 不需要安装 GCC（使用纯 Go SQLite 驱动 `modernc.org/sqlite`）
- ZLMediaKit 流媒体服务器（需提前部署）

### 本地开发

```bash
# 进入后端目录
cd backend

# 安装依赖（含 bcrypt + pure Go SQLite）
go mod tidy

# 运行（开发模式）
go run .

# 编译
go build -o server.exe .

# 自定义配置运行（环境变量覆盖 config.json）
SERVER_ADDR=:9090 go run .
```

启动后：
- 主页: `http://localhost:80`
- 管理后台: `http://localhost:80/admin.html`

### 生产部署

```bash
# 编译 Linux amd64 精简二进制（输出到 build/liveserver）
cd backend
make

# 或手动编译
CGO_ENABLED=0 GOOS=linux GOARCH=amd64 go build -ldflags="-s -w" -o build/liveserver .

# 复制配置模板并编辑
cp config.example.json config.json
vim config.json

# 运行
./build/liveserver
```

建议配合 systemd (Linux) 或 NSSM (Windows) 将程序注册为系统服务。

## 前后端职责划分

| 功能 | 原实现 | 新实现 |
|------|--------|--------|
| 门禁口令校验 | 前端 `prompt()` 明文比对，密码硬编码在 HTML | 后端 `POST /api/verify` 服务端校验，Token 机制 |
| 用户注册与管理 | 无 | 用户注册 → 管理员审核 → bcrypt 密码哈希存储 |
| 用户登录 | 无 | `POST /api/login` → 含角色 Token → 免门禁口令 |
| 流列表获取 | 前端直接调用 ZLM API，API Secret 暴露 | 后端代理转发，Secret 仅存于后端 |
| 流地址获取 | 前端拼接硬编码的服务器 IP | 后端 `/api/stream-url` 动态返回 |
| 视频播放 | 前端 flv.js 直连 ZLM | 不变，前端仍直连 ZLM 拉流 |
| 访客记录 | 无 | `action_logs` 表按关键操作记录（验证/注册/登录/观看/上传/下载），管理后台分页查询 |
| 管理后台 | 无 | `/admin.html` 管理员面板，完整数据查询（操作/鉴权/观看记录）与用户管理 |
| 云盘文件 | 无 | `/cloud.html` 鉴权页面，权限分级（游客仅下载、用户可上传、管理员可管理），支持上传者追踪（`cloud_files` 表），大文件流式下载，后端 `/api/cloud/*` 含上传/下载/列表/空间/新建文件夹/删除/移动 |
| 前端架构 | 各页面独立内联样式 | 共享 `css/common.css`（毛玻璃主题 + 通用组件）+ `js/utils.js`（工具函数 + XSS 防护），背景图 WebP 压缩 |

## 技术栈

- **后端**: Go 标准库 `net/http` + `golang.org/x/crypto/bcrypt` + `modernc.org/sqlite`（纯 Go SQLite 驱动，无 CGO 依赖）
- **前端**: 原生 HTML/CSS/JS（无框架依赖，兼容性好）+ [flv.js](https://github.com/bilibili/flv.js) 播放器
- **流媒体**: ZLMediaKit (RTMP/FLV/HLS)
- **数据库**: SQLite3 (WAL 模式)
- **密码安全**: bcrypt 哈希（Cost=10）

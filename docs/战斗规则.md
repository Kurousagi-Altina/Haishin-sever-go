# 跑团桌面的战斗规则（D&D 5e 2024）

本文先把 2024 版规则理一遍，再说明跑团桌面怎么处理。总原则：**只提示，不强制**——系统帮你记、帮你算、到点提醒，最后由玩家和 GM 决定做不做；每类提示都能在「⚙ 设置 → 战斗提示」里单独关掉，所有数字都能手动改。

## 0. 生命值归零与死亡豁免

**规则**
- 只有玩家角色在 0 生命值时倒地昏迷、进行死亡豁免（每回合 d20：≥10 成功、<10 失败，天然 1 记两次失败，天然 20 恢复 1 点生命值；三次成功稳定，三次失败死亡）。0 生命值时再受伤记一次失败（重击记两次），单次伤害不低于生命上限直接死亡。
- 怪物和其他非玩家角色掉到 0 生命值就死亡，没有死亡豁免。

**桌面怎么做**
- 「玩家角色」= 由玩家控制的棋子，或关联了人物卡的棋子。只有它们在 0 生命值时显示死亡豁免栏、能掷死亡豁免、再受伤时记失败；其他棋子掉到 0 生命值直接标「死亡」（先攻里自动跳过）。
- 想让某个重要 NPC 也做死亡豁免：把它分配给一个玩家控制，或给它关联人物卡。

## 1. 回合与动作经济

**规则**
- 自己的回合里可以：移动（不超过速度，可以拆开走）、执行**一个动作**、在有能力允许时执行**一个附赠动作**，外加一次顺手的物件互动（开门、拔剑）。
- **反应**：每轮一次，可以在别人的回合里用；在自己回合开始时恢复。
- 常用动作：攻击、疾走、撤离、闪避、协助、躲藏、影响、魔法（施法、用魔法物品）、预备、搜索、研究、使用。
- 施法时间写「1 个附赠动作」的法术用附赠动作；写「1 个反应」的用反应。
- **一回合只能用法术位施放一个法术**（2024 规则）：用法术位施放过一个法术后，同一回合不能再用法术位施法（戏法不受限）。

**桌面怎么做**
- 先攻条上显示当前行动者的「动作 / 附赠 / 反应 / 移动」使用情况；轮到某个单位时自动清零。
- 结算行动时按行动框里的「消耗」自动打勾（默认按说明文字判断：写了附赠动作就是附赠，写了反应就是反应）；也可以直接点格子手动勾选或取消。
- 本回合已经用法术位施过法、又要再用法术位时，提示一句 2024 规则；照样可以施放。
- 用了反应（借机攻击、拨挡攻击、盾牌术等）会在那个单位身上记「反应已用」，下次轮到它时恢复。

## 2. 借机攻击

**规则**
- 一个你看得见的生物**用它自己的移动、动作、附赠动作或反应**离开你的触及范围时，你可以用反应对它进行一次近战攻击（武器或徒手打击），这次攻击发生在它离开之前。
- 不会引发：执行了**撤离**动作；**传送**；被推、被拖、被别人移动（没有用它自己的移动）；带「飞掠」特质的生物。
- 没有反应可用、失能（麻痹、震慑、昏迷、石化等）的生物不能借机攻击。
- 相关能力（按卡上写的为准，系统不强制）：哨兵（目标撤离也能借机，命中后速度变 0）、长柄武器大师（进入触及时也能反击）、战地施法者（可以用法术代替借机攻击）、速捷（对你的借机攻击具有劣势）。前三个的提示见第 11 节。

**桌面怎么做**
- 战斗中拖动棋子时，系统按实际拖过的路线检查：路上有没有某个敌对生物原本能碰到它、之后又被它离开了触及范围。触及距离读角色卡 / 怪物卡上近战攻击写的「触及 X 尺」，默认 5 尺；也可以在棋子属性里直接填。
- 满足条件时，提示 GM（以及那个敌人的控制者）：「X 离开了 Y 的触及范围」，后面有「⚔ 借机攻击」按钮。点了就用 Y 的近战攻击打开行动框，预先选好 X 作为目标，结算后记 Y 的反应已用。
- 不提示的情况：移动的一方身上有「撤离」状态或卡上有「飞掠」；对方已经用过反应、处于失能类状态、看不见移动者（隐形、躲藏）；阵营是「中立」。
- 阵营默认按控制者判断：玩家控制的是一方，GM 控制的是另一方。可以在棋子属性里改成友方 / 敌方 / 中立（比如 GM 控制的 NPC 盟友）。
- 提示只是告诉你「可能」触发：要不要打、要不要让棋子退回去，都由 GM 决定。

## 3. 专注

**规则**
- 受到伤害时进行体质豁免，DC = 10 或这次伤害的一半（取较高，最高 30）；同时受到多次伤害就分别豁免。失败则专注结束。
- 失能或死亡时专注结束；开始专注另一个法术时，原来的专注结束。
- 战地施法者：维持专注的豁免具有优势。巫师杀手：被它伤害后的专注豁免具有劣势。

**桌面怎么做**
- 结算伤害时，记录里注明需要的 DC；后面有「🎲 专注豁免」按钮（GM 和这个单位的控制者看得到）。
- 由服务器掷：体质豁免加值读角色卡，会算上祝福 / 灾祸、力竭、判定修正里的豁免加值和优势（战地施法者、「对专注豁免有优势」之类；伤害来源有巫师杀手时劣势）。失败自动去掉专注状态，留在地图上的专注区域也随之消失。
- 反应减伤之后，按减少后的伤害重新给出 DC，伤害变成 0 时提示不用再豁免。

## 4. 回合开始 / 结束时的效果

**规则**
- 「闪避」持续到你下个回合开始。
- 很多效果要求「在每个回合结束时重复豁免，成功则效果结束」（如定身术、恐惧术），或「在每个回合开始时受到伤害」（如燃烧、酸液）。
- 有持续时间的效果按「轮」计时。

**桌面怎么做**
- 轮到某个单位时，自动去掉它的「闪避」；它的回合结束时，自动去掉「撤离」。
- 状态可以带「回合结束时豁免」（属性 + DC）或「回合开始时受到伤害」（骰子 + 类型）。到点时记录里提示 GM 和控制者，并带上按钮：「🎲 豁免」由服务器掷，成功自动去掉这个状态；「🔥 结算伤害」按伤害类型算抗性后扣血。
- 行动框会从法术说明里认出「每个回合结束时重复豁免」「每个回合开始时受到 XdY 伤害」，自动带到附加的状态上；状态面板里也可以手动设置。
- 原有的轮数倒计时不变：在该单位回合结束时减 1。

## 5. 传奇动作、传奇抗性、充能

**规则（2024 怪物图鉴）**
- **传奇动作**：每轮有 N 次（巢穴中通常 +1），在另一个生物的回合结束后可以使用一次；在自己回合开始时全部恢复。
- **传奇抗性（X/日）**：豁免失败时可以改为成功。
- **充能 X–6**：用过之后，在它每个回合开始时掷 d6，掷出 X 或更高就恢复。

**桌面怎么做**
- 关联了怪物卡的棋子在战斗开始时自动加上资源：「传奇动作 N/N」、「传奇抗性 X/X」、每个带「（充能 X–6）」的能力各一个。数字可以在棋子属性里改（比如在巢穴中 +1）。
- 每个单位的回合结束时，提示 GM 哪些怪物还有传奇动作可用；点按钮扣一次并打开它的怪物卡。轮到这个怪物时自动恢复满。
- 怪物豁免失败、还有传奇抗性时，记录里的这个目标后面出现「传奇抗性」按钮：扣一次，并按「豁免成功」重新结算伤害和状态（与反应减伤用同一套算法）。
- 充能能力用过之后（资源变成 0），轮到这个怪物时由服务器自动掷 d6，掷够就恢复，结果写进记录（GM 的怪物对玩家显示为暗骰）。

## 6. 多重攻击

**规则**：怪物的「多重攻击」写明一次动作里进行哪几种攻击、各几次，例如「进行两次啮咬攻击和一次爪击」。

**桌面怎么做**：怪物卡上的「多重攻击」有 ⚡ 按钮，点开一个小条，列出它要做的每种攻击和次数，点一次就打开那种攻击的行动框，用完一次减一次；顺序、目标、要不要换成别的攻击都由 GM 决定。认不出来时，小条里列出卡上所有可用的攻击供选择。

## 7. 武器精通（2024）

**规则**：有「武器精通」特性的角色，用掌握了精通的武器攻击时可以触发该武器的精通词条：
- **侵扰**：命中并造成伤害后，你对该生物的下一次攻击检定具有优势（到你下回合结束）。
- **削弱**：命中后，该生物的下一次攻击检定具有劣势（到你下回合开始）。
- **失衡**：命中后，目标进行体质豁免（DC 8 + 攻击所用属性调整值 + 熟练加值），失败则倒地。
- **推离**：命中体型不超过大型的生物时，可以把它直线推离至多 10 尺。
- **擦掠**：攻击失手时，仍造成等于属性调整值的伤害（同武器类型）。
- **横扫**：近战命中后，可以对原目标 5 尺内、你触及内的另一个生物再攻击一次，伤害不加属性调整值（为负时照加），每回合一次。
- **缓速**：命中并造成伤害时，目标速度 −10 尺，直到你下回合开始，不叠加。
- **迅击**：轻型武器的额外攻击改为攻击动作的一部分，不占附赠动作，每回合一次。

**桌面怎么做**
- 行动框的「武器精通」读角色卡武器上写的精通；没写、但角色有「武器精通」特性时，从本地规则库的武器表补上。可以改或清空。
- 攻击结算后，记录里给出手的人和 GM 显示对应按钮：命中时「侵扰」（施放者获得对该目标的下一次攻击优势，攻击后自动用掉）、「削弱」（目标获得削弱状态，它下次攻击劣势，攻击后用掉）、「失衡」（打开体质豁免，DC 按命中加值 + 8 估算，可改，失败倒地）、「推离 10 尺」（沿施放者 → 目标的方向推开）、「缓速 −10 尺」（目标速度显示减 10）、「横扫」（用同一把武器再打开一次攻击）；失手时「擦掠伤害」（按命中加值 − 熟练加值估算属性调整值）。
- 迅击只是说明，不额外处理（动作经济里照常手动勾选）。

## 8. 徒手打击：擒抱与推撞（2024）

**规则**
- 徒手打击：命中 = 力量调整值 + 熟练加值，伤害 = 1 + 力量调整值（钝击）。
- 擒抱 / 推撞不掷攻击，改由目标进行**力量或敏捷豁免（由目标选择）**，DC = 8 + 力量调整值 + 熟练加值；目标至多大你一个体型，擒抱还需要一只空手。擒抱失败 → 受擒；推撞失败 → 倒地，或被推开 5 尺。
- 受擒的生物可以用动作挣脱：力量（运动）或敏捷（特技）检定对抗同一个 DC。

**桌面怎么做**
- 属性面板「徒手」一行：👊 打击、🤼 擒抱、推撞。擒抱 / 推撞的豁免是「力量或敏捷（目标取高）」，服务器自动用目标加值高的那项，记录里注明选了哪项。
- 擒抱成功时，「受擒」状态记下 DC 和擒抱者；状态旁有「挣脱」按钮，由服务器掷运动 / 特技（取高，没有技能时用属性调整值）。
- 推撞默认附加倒地；想推开就把附加状态改成（无），结算后点记录里的「推开 5 尺」。

## 9. 职业特性（2024 玩家手册）

**规则**
- **偷袭**（游荡者）：每回合一次（任何人的回合都算），用灵巧或远程武器命中，且有优势、或目标 5 尺内有你的盟友（不失能）且你没有劣势时，额外造成 ⌈游荡者等级 ÷ 2⌉d6 伤害（同武器类型，重击时翻倍）。
- **狂暴**（野蛮人）：附赠动作进入；钝击 / 穿刺 / 挥砍抗性，力量检定与豁免优势，用力量进行的攻击伤害 +2（9 级 +3、16 级 +4）。次数：2（3 级 3、6 级 4、12 级 5、17 级 6）。
- **回气**（战士）：附赠动作，恢复 1d10 + 战士等级生命。次数：2（4 级 3、10 级 4）。
- **动作如潮**（战士）：本回合额外获得一个动作（不能是魔法动作）。次数：1（17 级 2）。
- **诗人激励**（吟游诗人）：附赠动作，60 尺内一名其他生物获得一颗激励骰（d6，5 级 d8、10 级 d10、15 级 d12），次数 = 魅力调整值（至少 1）。

**桌面怎么做**
- 属性面板「职业」一行：😡 狂暴 / 结束狂暴、回气、动作如潮、🎵 诗人激励，按钮上显示剩余次数。次数记在棋子资源里（没有就按等级表新建），可以手动改。职业等级读人物卡的「职业」栏（如「战士 3 / 游荡者 2」），只写职业名时用总等级。
- 狂暴：加上「狂暴」状态（原有的抗性和力量豁免优势照常生效），记附赠动作；狂暴中用近战（含投掷）攻击时，行动框里「狂暴伤害 +N」默认勾上，伤害自动加上，远程攻击默认不勾。
- 回气：打开治疗行动（1d10 + 战士等级），目标是自己。动作如潮：本回合的「动作」恢复可用，先攻条上显示「如潮」。诗人激励：打开附加「诗人激励」状态的行动，选目标即可。
- 偷袭：命中后记录里出现「偷袭 +Nd6」（出手的人和 GM 看得到，重击自动翻倍），点了打开伤害行动并预选目标；本回合用过就不再出现。系统判断是否有优势、目标 5 尺内有没有盟友，看不出满足条件时按钮带「？」，由 GM 决定。

### 9.1 共用：子职、额外攻击

- 子职按人物卡的「子职」栏识别，没写时看特性 / 资源里有没有子职特有的名字（如「巨人之力」「火之符文」）。导入的卡没写子职时，角色卡顶部可以手动填（玩家能改自己的卡）。
- **额外攻击**（战士 5 级 2 次、11 级 3 次、20 级 4 次；其他职业卡上有「额外攻击」时 2 次）：战斗中用「动作」消耗进行武器攻击时，先攻条的动作要打满这么多下才算用掉，每一下提示「第 k/n 击」。动作如潮后重新计数。

### 9.2 战士（2024 玩家手册）

**规则**
- 2 级 **战术思维**：属性检定失败时花一次回气，加 1d10；加上后仍失败则不消耗。
- 5 级 **战术转进**：用回气时可以移动至多一半速度，不引发借机攻击。
- 9 级 **不屈**：豁免失败时重掷并加战士等级，必须用新结果。次数 1（13 级 2、17 级 3），长休恢复。
- 9 级 **战术主宰**：攻击时可以把武器精通换成推离、削弱或缓速。
- 13 级 **究明攻击**：攻击失手后，直到你下个回合结束，对该生物的下一次攻击具有优势。
- **巨武器战斗**（战斗风格专长）：双手持握近战武器攻击时，伤害骰掷出 1 或 2 都按 3 算。

**桌面怎么做**
- 属性面板「职业」行：🧠 战术思维（扣一次回气、掷 1d10，提示仍失败就加回来）；9 级起「不屈」（给自己掷的豁免用：扣次数、掷 1d20 + 战士等级）。
- 回气：5 级起同时挂上「撤离」（本回合移动不引发借机）。
- 不屈：服务器掷的豁免失败后，记录里出现「不屈（重掷 +N）」，由服务器重掷（加豁免加值和战士等级），成功则按成功重新结算伤害和状态；不占反应。
- 究明攻击：13 级起攻击失手后，记录里出现「究明攻击」，点了给自己挂上对该目标的优势（2 轮，攻击后用掉，和精通「侵扰」同一套）。
- 战术主宰：行动框里的「武器精通」本来就可以随意改，选推离 / 削弱 / 缓速即可。
- 巨武器战斗：武器属性写了「双手」的近战攻击，行动框专长一行的「巨武器战斗（1、2 按 3）」默认勾上（多用武器默认不勾，双手握持时自己勾）；勾上后伤害骰写成 `2d6mi3`（每颗至少 3），重击翻倍时照样生效。

### 9.3 符文骑士（塔莎的万事坩埚）

**规则**
- 3 级 **巨人之力**：附赠动作，1 分钟：体型变为大型，力量检定和力量豁免优势，每回合一次武器或徒手命中额外 1d6（10 级 1d8、18 级 1d10，18 级可以变为巨型、触及 +5 尺）。次数 = 熟练加值，长休恢复。
- **符文**（3 级学两种，之后增加；每种的主动能力短休 / 长休恢复一次，15 级符文大师起两次）：符文 DC = 8 + 熟练加值 + 体质调整值。
  - 火焰符文：武器命中时发动，目标力量豁免，失败则被束缚 1 分钟，每回合开始受到 2d6 火焰伤害，每回合结束重复豁免。
  - 云雾符文：你或 30 尺内你看得见的生物被攻击命中时，用反应把这次攻击改给你 30 尺内另一个生物（攻击者除外），用同一个命中值。

**规则**
- 7 级 **灵光一闪**：你或 30 尺内看得见的生物属性检定或豁免失败时，用反应加上你的智力调整值（次数 = 智力调整值，长休恢复）。11 级 储法物品、20 级 奇械之魂（手动）。
- 魔炮师：3 级 **魔能炮台**（见第 12 节随从）；5 级 **奥法火器**（通过刻了符文的法器施放奇械师法术时，一次伤害掷骰 +1d8）；9 级 **高爆炮台**（炮台伤害 +1d8、可以引爆，已在炮台模板里）；15 级 **要塞阵地**（可以同时有两门炮台；炮台 10 尺内的你和盟友享有半身掩护）。
- **战俑**（种族）：构装坚韧——毒素抗性，对抗中毒的豁免优势；内嵌防护的 +1 AC 默认已经在卡上的 AC 里。

**桌面怎么做**
- 属性面板：🔧 魔能炮台（打开「新建随从」，模板和主控已选好）、7 级起「💡 灵光一闪」（给自己掷的检定用：扣次数、记反应）。
- 服务器掷的豁免失败后，记录里出现「灵光一闪 +N（名字）」（30 尺内的奇械师），由服务器加上智力调整值重新判定，成功则重新结算。
- 奥法火器：5 级起施放有伤害的法术时，行动框专长一行出现「奥法火器 +1d8」（默认勾上）。
- 要塞阵地：15 级起，攻击魔能炮台 10 尺内的友方时，确认目标会把掩护至少提到半身并写进记录。
- 战俑：种族栏写了「战俑」时，服务器自动给毒素抗性和对中毒的豁免优势。

## 10. 反应法术

**规则**
- **法术反制**（三环，2024）：看见 60 尺内一个生物施法时用反应施放；施法者进行体质豁免对抗你的法术豁免 DC，失败则那道法术作废，用来施法的动作被浪费，**用过的法术位不消耗**。
- **炼狱叱喝**（一环）：被你看得见、60 尺内的生物伤害时用反应施放；它进行敏捷豁免，失败受 2d10 火焰伤害，成功减半（每高一环 +1d10）。
- **吸收元素**：受到强酸 / 寒冷 / 火焰 / 闪电 / 雷鸣伤害时用反应施放；对这种伤害有抗性直到你下回合开始，包括触发的这次伤害。
- **羽落术**等不依赖结算结果的反应法术：照常施放。

**桌面怎么做**
- 法术结算后，记录里给附近（60 尺内）带「法术反制」、反应没用过的单位显示「法术反制（名字）」按钮（自己控制的单位，GM 看得到所有）。点了由服务器掷施法者的体质豁免，对抗反制者人物卡上的法术 DC：失败就把这次结算整个撤销（和 GM 撤销用同一份快照，专注也一起撤掉），并把施法者人物卡上用掉的法术位退回；反制者记反应已用，客户端扣一个三环或更高的法术位。一道法术只能被反制一次。
- 受到伤害的目标后面：有「炼狱叱喝」时显示按钮，按本地规则库填好行动框（敏捷豁免、2d10 火焰、成功减半），施放者是被打的人、目标预选伤害来源、消耗设为反应；有「吸收元素」且这次伤害里有元素伤害时显示按钮，按减伤重新结算那部分元素伤害（减半），并挂上「吸收X」临时抗性状态，轮到这个单位时自动去掉，扣一个一环法术位。
- 服务器结算时按伤害类型记下每个目标实际受到的伤害（`types`），吸收元素按这个算。
- 反制只是提示：系统没法在施法「之前」插队，按钮出现在结算之后，反制成功等于撤销那次结算。

## 11. 专长（2024 玩家手册）

**规则（只列和战斗结算有关的部分）**
- **巨武器大师**：用重型武器、作为自己回合攻击动作的一部分命中时，伤害加熟练加值；近战重击或把生物打到 0 生命值后，可以用附赠动作再用这把武器攻击一次（每回合一次）。
- **长柄武器大师**：用长棍、矛或同时有重型和触及的武器执行攻击动作后，附赠动作用另一端攻击，1d4 钝击；有生物进入你的触及范围时，可以用反应对它近战攻击。
- **哨兵**：5 尺内的生物执行撤离、或攻击命中你以外的目标后，你可以对它借机攻击；借机攻击命中后，它本回合剩余时间速度为 0。
- **神射手**：远程武器攻击无视半身和四分之三掩护；远距离射击和近身有敌人时都没有劣势。
- **强弩专家**：近身有敌人时用弩攻击没有劣势；无视装填。
- **擒抱者**：攻击你擒住的生物具有优势；徒手命中时可以同时伤害并擒抱（每回合一次）。
- **战地施法者**：专注豁免具有优势；可以用反应施放一道（一个动作、只以对方为目标的）法术代替借机攻击。
- **巫师杀手**：被你伤害的专注中生物，专注豁免具有劣势；智力 / 感知 / 魅力豁免失败时可以改为成功（短休 / 长休恢复）。
- **幸运**：熟练加值个幸运点（长休恢复），花一点让自己的一次 D20 检定具有优势，或让对你的一次攻击检定具有劣势。
- **防御式决斗**：持灵巧武器被近战攻击命中时，用反应让 AC 加熟练加值（可能让攻击落空）。
- **拦截**（战斗风格）：持盾或武器，5 尺内的另一个生物被命中时，用反应减伤 1d10 + 熟练加值。
- **盾牌大师**：介入盾牌——要做敏捷豁免、成功只受一半伤害的效应，成功时用反应改为不受伤害；盾击推开或击倒。
- **酒馆斗殴者 / 徒手战斗**：徒手打击伤害改为 1d4 / 1d6（徒手战斗不拿武器和盾时 1d8）+ 力量调整值。
- 其余（凶蛮打手、冲锋手、双持客、元素掌控、警戒、箭术 / 对决 / 防御等固定加值）：按角色卡上的数字和说明手动处理；固定加值默认已经算在卡上的攻击 / AC / 先攻里，系统不再重复加。

**桌面怎么做**（都看角色卡特性 / 条目里有没有这个名字）
- 行动框：重型武器（武器属性写了「重型」，或是巨斧、巨剑、巨锤、长弓、重弩、戟、长柄刀、长矛、骑枪）显示「巨武器大师 +熟练加值」勾选框，消耗是「动作」时默认勾上，附赠攻击默认不勾。
- 确认目标时：神射手自动去掉半身 / 四分之三掩护、远距离劣势和近身射击劣势；强弩专家去掉近身射击劣势；擒抱者攻击自己擒住的目标自动优势。只有真的改了判定时才在记录里写一句。
- 记录里的按钮：近战重击或打倒目标后「顺势斩（附赠攻击）」（每回合一次，消耗设为附赠）；用长柄武器攻击后「长柄打击（附赠）」（1d4 钝击 + 卡上这把武器的固定加值）；敌人攻击命中别人、而你（哨兵）就在它 5 尺内时「哨兵：借机」；哨兵的借机攻击命中后「阻拦：速度 0」（挂上「阻拦」状态，目标回合结束时自动去掉）。
- 被打的一方：近战攻击命中后「招架（防御式决斗）」，按 AC + 熟练加值重新判定，不再命中则伤害和状态作废；敏捷豁免成功受了一半伤害时「介入盾牌」，伤害改为 0。旁边 5 尺内有「拦截」的盟友：「拦截（名字）」，由服务器掷 1d10 + 熟练加值按减伤重新结算，记那个盟友的反应已用。
- 借机提示：撤离的单位离开哨兵的触及仍然提示；单位进入长柄武器大师（卡上有长柄武器）的触及时提示反击；有战地施法者的单位在借机提示后多一个「🪄 用法术」按钮，打开角色卡，下一次施法自动设为反应并预选那个单位（3 分钟内有效）。
- 专注豁免：伤害来源有巫师杀手时，记录里写「（巫师杀手：劣势）」，点「专注豁免」由服务器按劣势掷；战地施法者照旧优势。
- 幸运：属性面板「专长」行的「🍀 幸运」按钮扣一个幸运点（棋子资源里没有就按熟练加值新建），挂上「幸运」状态：下一次攻击检定、或由服务器掷的豁免（行动豁免、专注豁免、状态豁免）自动取优势并去掉状态；属性检定请在掷骰框里自己选优势。让攻击者劣势由 GM 处理。
- 徒手打击按钮：卡上有徒手战斗 / 酒馆斗殴者时伤害默认 1d6 / 1d4 + 力量。

## 12. 随从 / 召唤物

**规则（2024）**
- 魔宠（寻获魔宠）：自己投先攻、有自己的回合，不能攻击（链契术士等特性另说）。
- 召唤法术（召唤野兽、召唤亡灵等）、龙兽同伴：和主人共用先攻，回合排在主人之后。
- 野兽伙伴、钢铁卫士、魔能炮台：在主人回合内行动，主人花附赠动作下令 / 激活；不下令时只能闪避（炮台不动）。
- 这类召唤物的攻击加值、豁免 DC 大多直接用主人的法术攻击加值和法术豁免 DC，生命值常按主人等级算（魔能炮台 = 奇械师等级 × 5）。
- 召唤物生命值降到 0 就消失 / 摧毁，没有死亡豁免。

**桌面怎么做**
- 角色卡新增一类「随从 / 召唤物」（kind `summon`），卡上设「主控」= 主人的角色卡。玩家可以给自己的角色建随从卡；GM 可以把怪物卡「设为随从」（例如从图鉴导入的魔宠），卡和棋子归主控的玩家。
- 跟随主控：随从卡自己没有施法数据时，法术攻击、法术 DC、施法属性调整值、熟练加值都取主控的。卡上写「法术攻击」「敏捷豁免」但没写数字的条目，点 ⚡ 时会自动填上主控的数值。
- 卡上文字可以写【…】，按主控实时换算（主控升级后不用改卡）：【法术攻击】【法术DC】【熟练】【等级】【施法属性】【力量】…【魅力】【奇械师等级】；【奇械师等级×5】（乘）、【智力≥1】（至少）、【奇械师9级：3d8｜2d8】（职业等级达到时取前一个）。
- 模板：「魔能炮台」（火焰喷射 / 力场弩炮 / 护卫 / 引爆，9 级起伤害骰自动加 1d8）和「空白随从」。护卫的临时生命值设为「只掷骰」：只给掷骰按钮，不自动加到谁身上，按房规自己调整后手动填。
- 随从卡可以直接编辑（名字、AC、生命上限、速度、每个条目的文字和「只掷骰」）。
- 棋子图标：随从卡上「棋子图标」从资产库选一张，或直接上传图片；以后放置都用它，已放置的棋子一起换。
- 行动方式（卡上可选）：
  - 跟随主控（默认）：不进先攻条，在先攻条上挂在主控后面（小头像，主控行动时一起高亮）。主控的回合里，主控的玩家可以自由移动、指挥随从：移动计入随从自己的「本回合已移动」，行动消耗记在主控身上；主控回合结束时随从的「回合结束」效果一起结算（持续回合数倒数、直到回合结束的状态、重复豁免提示），主控回合开始时随从的动作 / 反应恢复、闪避结束。
  - 独立先攻：像普通生物一样进先攻条、有自己的回合（魔宠按规则是这种）。GM 在战斗中放置时自动掷先攻；已经在场的，在先攻栏把它加进去。
  - 跟随主控的随从如果被手动加进了先攻条，就按独立先攻处理。
- 放置随从棋子：放在主控棋子旁边，生命上限按规则换算，不自动对玩家隐藏。
- 随从生命值降到 0：直接「死亡」（= 摧毁 / 消失），不会昏迷，也没有死亡豁免。

## 13. 自动化一览与开关

### 13.1 手动豁免（每个角色单独设置）

- 属性面板「豁免：☑ 自动掷豁免」默认勾上：需要豁免时由服务器掷并结算。
- 不勾时，行动结算到这个角色的豁免先不掷：记录里写「待掷豁免」，并提示要掷什么、成败各会怎样（如「需要敏捷豁免 DC 15——成功：只受一半伤害；失败：受到 12 火焰伤害，陷入「倒地」」），控制它的玩家会弹出提醒。
- 玩家可以点「🎲 掷 X 豁免」由服务器当场掷（加值、优势、反射闪避等照常算），或者用自己的骰子掷完点「成功」/「失败」；之后伤害（用原来那次掷出的伤害）和状态照样自动结算，记录里多一条「（补掷豁免）」/「（自己掷：成功 / 失败）」。GM 也能替它点。
- 专注豁免、状态的重复豁免本来就是点按钮才掷，不受这个开关影响。

### 13.1.1 手动先攻（每个角色单独设置）

- 同一行「自动掷：☑ 豁免 ☑ 先攻」，先攻默认勾上：GM 点「准备」/「伏击」开战、战斗中从角色卡放下棋子、点「掷先攻（N）」时，都会替它自动掷。
- 不勾时这些自动掷都跳过它：战斗页标「自己掷」，列表上方显示「⏳ 等待自己掷先攻：…」，控制它的玩家弹出提醒（含先攻加值）。「准备」/「伏击」这时只掷其他人、不自动开战，GM 等大家掷完再点「开始战斗」。
- 玩家在战斗页这一行点「🎲 普通」「优势」「劣势」由服务器掷（属性面板先攻那一行也有 🎲 / 优势 / 劣势）。
- 先攻显示为「🎲骰值 加值 = 总值」（先攻条上是总值下面的小字）；手动改过先攻值的只显示总数。
- 「开始战斗」时如果还有没掷先攻（先攻为 0）的单位，会先确认。

### 13.2 一直生效的基础自动化

这些是桌面的基本功能，不做开关（结果都能撤销或手动改）：
- 攻击对 AC 判定（天然 20 / 1）、伤害骰掷骰、重击翻倍。
- 豁免掷骰（勾了自动掷豁免的角色）、成功减半。
- 伤害结算：临时生命先扣，伤害类型的抗性 / 免疫 / 易伤，非魔法攻击的抗性，0 生命值倒地 / 昏迷 / 死亡，死亡豁免。
- 状态：行动附带的状态、状态免疫，按轮数倒计时，专注（新专注取代旧专注、倒地结束专注、受伤提示专注豁免）。
- 施法：从角色卡施放时扣法术位（行动框里可以取消）、升环、戏法强化、持续区域。
- 随从：数值跟随主控，跟随主控的随从和主控一起开始 / 结束回合。
- 角色卡上手动加的「判定修正」，以及卡上写的「抗性 / 免疫 / 优势」行。

### 13.3 可以单独关掉的分类（「⚙ 设置 → 战斗自动化」，GM 设置，全房间生效，默认全开）

| | 武器精通 | 侵扰、削弱、失衡、推离、擦掠、横扫、缓速的后续按钮 |

| 职业特性 | 职业特性（总开关）+ 分职业 | 战士 / 符文骑士、武僧 / 四象武者、牧师 / 战争领域、德鲁伊 / 星辰结社、法师 / 预言师、奇械师 / 魔炮师、野蛮人 / 游荡者 / 吟游诗人（狂暴、偷袭、诗人激励），各自的按钮、记录里的按钮和自动处理（第 9 节） |
| 专长与种族 | 专长 | 第 11 节的全部专长（含巨武器战斗、徒手战斗 / 酒馆斗殴者） |
| | 种族特性 | 龙裔吐息武器 / 龙族飞翼、化兽者化兽 / 迅捷 |

关掉某一类后，对应的提示、按钮和自动处理都停止，状态、资源照样可以手动管理；随时可以再打开。

## 14. 判定细节（多人实战推演后补充）

- **敌我**：棋子属性里手动设的「阵营」优先；否则玩家控制的、关联玩家角色卡的（GM 暂时代管的队友也算）、主控是玩家角色的随从 = 友方，其他 = 敌方。借机攻击、远程近身劣势、云雾符文、符文之盾、导引打击、法术反制、只影响敌人的范围法术都按这个判断：
  - 云雾符文 / 符文之盾只在敌人的攻击命中时给；导引打击只帮自己一方；法术反制只对敌方施法者给按钮。
  - 远程攻击时 5 尺内有看得见你、没失能的敌人 → 劣势，怪物被玩家贴身也一样。
- **队友数值**：关联玩家角色卡的棋子，即使没分配给玩家、由 GM 代管，玩家也能看到准确的生命值和 AC（敌人仍是按比例的血条）。
- **先攻同值**：先比加值（棋子上填的加值，否则掷先攻时用的角色卡加值），再随机。
- **死掉的不当目标**：范围自动选目标时跳过已死亡的生物（玩家角色倒地是昏迷，仍会被选中）；在尸体和活着的生物叠在一起的地方点选，优先选活着的。打死目标后，震慑拳、火焰符文、巨人之力、神圣打击、原力蛮击这类后续按钮不再出现（顺势斩照常）。
- **范围识别**：2024 怪物卡的光环写法「15 尺内魔蝠可见的生物」「其 10 尺内的每个生物」识别为以自身为中心的圆；「60 尺内一名生物」仍是射程。
- **只影响敌人的范围**：说明里有「光环内敌人」「敌对生物」「指定任意生物不受影响」的（灵体卫士等），自动选目标时排除自己一方，可以再手动点选。
- **状态持续时间**：行动框「附加状态」后面可以选「按轮数 / 到施放者下回合结束 / 到施放者下回合开始」。解析规则文字时：「持续至魔蝠的下个回合结束」「直到你的下一回合开始」跟着施放者的回合走（在施加的那个回合里不会提前结束）；「直到目标的下一回合结束」= 1 轮；「1 分钟」= 10 轮。
- **充能**：用了「（充能 5~6）」这类能力，自动扣掉棋子上的「充能·X」计数，它回合开始时服务器掷充能；还没充好时只提示，不拦。
- **持续区域的回合时机**：区域记下「在其中开始回合 / 结束回合」时生效（从规则文字识别）。轮到的生物在区域里开始回合、或刚结束回合的生物在区域里时，控制区域的一端（GM 或施法的玩家）在先攻条下方看到「⚡ 区域：某某 在区域内开始回合」按钮，点一下只对它结算；每回合限一次的区域照样排除本回合结算过的。
- **借机攻击**：发生在对方离开触及之前，所以不按它移动后的位置算掩护和距离；近战攻击在行动框里显示的「射程」就是触及，不会被当成远程。玩家可以借机攻击、要做专注豁免时会弹提示。
- **完全掩护**：多个目标里有处于完全掩护的，跳过它并提示。
- **动作经济提醒**：行动框的「消耗」后面会提示本回合动作 / 附赠动作 / 反应已经用过，或这回合已经用法术位施过法（2024：每回合只能用法术位施一个法术）。只提示，照样能结算。
- **法术位**：棋子资源里的「N 环法术位」和角色卡的法术位互相同步（施法、角色卡上改、棋子上 −/+ 都会两边一起变）。
- **奥法火器**：多目标的攻击法术（灼热射线）只给第一个命中的目标加 1d8；豁免类（粉碎音波）加在共用的伤害骰上。
- **火焰符文**：命中时先结算额外 2d6 火焰（重击 4d6），再让目标做力量豁免。
- **龙裔**：种族文字里写了血统颜色（如「龙裔 金龙」）就自动有对应伤害类型的抗性（受「按特性名自动识别判定修正」开关控制）。
- **死亡豁免**：轮到 0 生命值的玩家角色时，GM 也能在先攻条上点「💀 死亡豁免」替它掷（代管的角色、缺席的玩家）。
- **规则库**：召雷术的落雷范围改为落点 5 尺半径（60 尺是雷云大小）。
